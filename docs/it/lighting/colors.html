Illuminazione

Colori#

Progetto di esempio examples/Sources/08-BasicLighting, si esegue con swift run BasicLighting. Scarica tutti gli esempi oppure guarda come eseguirli.

L'illuminazione è l'arte di calcolare di che colore deve apparire una superficie.
Prima di qualsiasi vero calcolo di luce ci servono un modello del colore e una scena da illuminare.

Il colore come numeri#

Un colore è fatto di tre numeri: quanto rosso, quanto verde e quanto blu.
Negli shader ogni canale è un float in cui 0 è niente e 1 è la piena intensità.

float3 coral = float3(1.0, 0.5, 0.31);

Il colore che vediamo su un oggetto è la parte della luce in arrivo che l'oggetto riflette.
Un oggetto color corallo illuminato da luce bianca riflette tutto il rosso, metà del verde e circa un terzo del blu, e assorbe il resto.
Nel codice la riflessione è una moltiplicazione componente per componente:

float3 lightColor  = float3(1.0, 1.0, 1.0);
float3 objectColor = float3(1.0, 0.5, 0.31);
float3 result = lightColor * objectColor;   // (1.0, 0.5, 0.31)

Con una luce verde lo stesso oggetto appare molto diverso:

float3 lightColor = float3(0.0, 1.0, 0.0);
float3 result = lightColor * objectColor;   // (0.0, 0.5, 0.0)

Non c'è luce rossa o blu da riflettere, quindi resta solo un verde scuro.
Quella singola moltiplicazione è il cuore di ogni modello di illuminazione di questa serie.

Una scena da illuminare#

Ci servono due cose: un oggetto, e qualcosa che mostri dov'è la luce.
Sono entrambi cubi, disegnati con due pipeline state diversi.

La fragment function dell'oggetto moltiplica i due colori:

struct FragmentUniforms {
    float3 objectColor;
    float3 lightColor;
};

fragment float4 fragment_main(VertexOut in [[stage_in]],
                              constant FragmentUniforms &uniforms [[buffer(1)]]) {
    return float4(uniforms.lightColor * uniforms.objectColor, 1.0);
}

struct FragmentUniforms {
    var objectColor: Float3
    var lightColor: Float3
}

var fragmentUniforms = FragmentUniforms(objectColor: [1.0, 0.5, 0.31],
                                        lightColor: [1, 1, 1])
encoder.setFragmentBytes(&fragmentUniforms,
                         length: MemoryLayout<FragmentUniforms>.stride,
                         index: 1)

struct FragmentUniforms {
    simd::float3 objectColor;
    simd::float3 lightColor;
};

FragmentUniforms fragmentUniforms{ {1.0f, 0.5f, 0.31f}, {1, 1, 1} };
encoder->setFragmentBytes(&fragmentUniforms, sizeof(FragmentUniforms), 1);

Il cubo della lampada non deve risentire affatto dell'illuminazione, quindi riceve una sua fragment function banale:

fragment float4 fragment_light(VertexOut in [[stage_in]]) {
    return float4(1.0);
}

Crea un secondo pipeline state che usa la stessa vertex function e fragment_light:

pipelineDescriptor.fragmentFunction = library.makeFunction(name: "fragment_light")
lightPipelineState = try device.makeRenderPipelineState(descriptor: pipelineDescriptor)

pipelineDescriptor->setFragmentFunction(library->newFunction(MTLSTR("fragment_light")));
lightPipelineState = device->newRenderPipelineState(pipelineDescriptor, &error);

Un descriptor è solo una ricetta.
Puoi cambiare una proprietà e crearne un altro state.

Disegnarli entrambi#

let lightPosition = Float3(1.2, 1.0, 2.0)

// The object
encoder.setRenderPipelineState(pipelineState)
uniforms.model = .identity
encoder.setVertexBytes(&uniforms, length: MemoryLayout<Uniforms>.stride, index: 1)
encoder.setFragmentBytes(&fragmentUniforms, length: MemoryLayout<FragmentUniforms>.stride, index: 1)
encoder.drawPrimitives(type: .triangle, vertexStart: 0, vertexCount: 36)

// The lamp
encoder.setRenderPipelineState(lightPipelineState)
uniforms.model = float4x4(translation: lightPosition) * float4x4(scale: [0.2, 0.2, 0.2])
encoder.setVertexBytes(&uniforms, length: MemoryLayout<Uniforms>.stride, index: 1)
encoder.drawPrimitives(type: .triangle, vertexStart: 0, vertexCount: 36)

const simd::float3 lightPosition = {1.2f, 1.0f, 2.0f};

// The object
encoder->setRenderPipelineState(pipelineState);
uniforms.model = matrix_identity_float4x4;
encoder->setVertexBytes(&uniforms, sizeof(Uniforms), 1);
encoder->setFragmentBytes(&fragmentUniforms, sizeof(FragmentUniforms), 1);
encoder->drawPrimitives(MTL::PrimitiveTypeTriangle, NS::UInteger(0), NS::UInteger(36));

// The lamp
encoder->setRenderPipelineState(lightPipelineState);
uniforms.model = translation(lightPosition) * scaling(simd::float3{0.2f, 0.2f, 0.2f});
encoder->setVertexBytes(&uniforms, sizeof(Uniforms), 1);
encoder->drawPrimitives(MTL::PrimitiveTypeTriangle, NS::UInteger(0), NS::UInteger(36));

Imposta il colore di sfondo della vista a qualcosa di scuro, per esempio (0.1, 0.1, 0.1), così la lampada risalta.
Adesso hai un cubo corallo piatto e un piccolo cubo bianco.
Quello corallo non ha ancora ombreggiatura, quindi le sue facce non si distinguono.
Il prossimo capitolo lo sistema.

Esercizi#

  • Cambia il colore della luce e prova a prevedere il colore dell'oggetto prima di eseguire.
    Mostra la soluzione

    Moltiplica canale per canale.
    Una luce (0.33, 0.42, 0.18) sull'oggetto corallo (1.0, 0.5, 0.31) dà (0.33, 0.21, 0.06), un verde oliva scuro.
    Una luce blu pura dà (0, 0, 0.31): l'oggetto appare blu scuro, perché il blu è l'unica luce che può riflettere.

  • Anima il colore della luce con sin(time) su ogni canale, a velocità diverse.
    Mostra la soluzione

    Imposta il colore della luce a ogni frame, per esempio in Swift Float3(sin(time * 2.0), sin(time * 0.7), sin(time * 1.3)) * 0.5 + 0.5.
    Il * 0.5 + 0.5 tiene ogni canale tra 0 e 1.
    Usa lo stesso valore per il colore del cubo della lampada, così la lampada corrisponde alla luce che emette.
