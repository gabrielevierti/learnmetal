Illuminazione

Mappe di illuminazione#

Progetto di esempio examples/Sources/09-LightingMaps, si esegue con swift run LightingMaps. Scarica tutti gli esempi oppure guarda come eseguirli.

Un materiale con un solo colore per oggetto è ancora troppo grossolano.
Una cassa di legno con un telaio d'acciaio è fatta di due materiali su una stessa superficie: il legno è opaco, l'acciaio è lucido.
La risposta è salvare le proprietà del materiale in texture, così possono variare da pixel a pixel.
Queste texture si chiamano lighting map.

Diffuse map#

Una diffuse map è ciò che i capitoli precedenti chiamavano semplicemente texture: un'immagine che contiene il colore della superficie in ogni punto.
Sostituisci il colore diffuse del materiale con una lettura dalla texture, e usa lo stesso valore per l'ambient:

struct Material {
    float shininess;
};

fragment float4 fragment_main(VertexOut in [[stage_in]],
                              constant FragmentUniforms &uniforms [[buffer(1)]],
                              texture2d<float> diffuseMap  [[texture(0)]],
                              texture2d<float> specularMap [[texture(1)]],
                              sampler mapSampler [[sampler(0)]]) {
    Light light = uniforms.light;
    float3 albedo = diffuseMap.sample(mapSampler, in.uv).rgb;

    float3 normal = normalize(in.normal);
    float3 lightDir = normalize(light.position - in.worldPosition);
    float3 viewDir = normalize(uniforms.viewPosition - in.worldPosition);
    float3 reflectDir = reflect(-lightDir, normal);

    float3 ambient = light.ambient * albedo;

    float diff = max(dot(normal, lightDir), 0.0);
    float3 diffuse = light.diffuse * diff * albedo;

    float3 specularColor = specularMap.sample(mapSampler, in.uv).rgb;
    float spec = pow(max(dot(viewDir, reflectDir), 0.0), uniforms.material.shininess);
    float3 specular = light.specular * spec * specularColor;

    return float4(ambient + diffuse + specular, 1.0);
}

Ricorda di accorciare la struct Material di Swift perché corrisponda.

Specular map#

La specular map è una seconda immagine, di solito in scala di grigi, che dice quanto intensamente ogni punto riflette.
Per la cassa è nera sul legno e chiara sul telaio d'acciaio, con graffi e usura dipinti sopra.
Nero significa nessun riflesso; bianco significa riflesso pieno.

Carica entrambe le immagini e collegale ai due slot delle texture:

diffuseMap = try! loader.newTexture(URL: url(for: "container2", "png"), options: options)
specularMap = try! loader.newTexture(URL: url(for: "container2_specular", "png"), options: options)

diffuseMap = loadTexture(device, commandQueue, "container2.png");
specularMap = loadTexture(device, commandQueue, "container2_specular.png");

encoder.setFragmentTexture(diffuseMap, index: 0)
encoder.setFragmentTexture(specularMap, index: 1)
encoder.setFragmentSamplerState(samplerState, index: 0)

encoder->setFragmentTexture(diffuseMap, 0);
encoder->setFragmentTexture(specularMap, 1);
encoder->setFragmentSamplerState(samplerState, 0);

Adesso luccica solo il bordo metallico della cassa, e il riflesso si spezza sui suoi graffi.

Un sampler, molte texture#

Entrambe le mappe vengono lette attraverso lo stesso sampler.
Un sampler descrive come leggere, e questo è quasi sempre uguale per tutte le mappe di un materiale: un solo sampler state è la norma.

Texture a un solo canale#

Una specular map in scala di grigi, caricata come RGBA, spreca tre canali.
Metal ha formati a un canale come .r8Unorm, e MTKTextureLoader carica così un PNG salvato in scala di grigi.
Nello shader leggi allora solo .r:

float specularStrength = specularMap.sample(mapSampler, in.uv).r;

Le pipeline di asset reali vanno oltre e impacchettano più mappe in scala di grigi nei canali di una sola texture, per esempio la roughness nel verde e la metalness nel blu.
Lo vedrai nella sezione PBR.

Esercizi#

  • Inverti la specular map nello shader, così luccica il legno e non l'acciaio.
    Mostra la soluzione

    Sottrai da uno il valore letto.

    float3 specularColor = 1.0 - specularMap.sample(mapSampler, in.uv).rgb;
  • Usa una specular map colorata e guarda come tinge i riflessi.
    Mostra la soluzione

    Nello shader non cambia niente: il termine specular è già moltiplicato per l'rgb della mappa.
    Una mappa dipinta di blu sopra l'acciaio dà lì riflessi blu.
    È così che nel modello di Phong si fanno i metalli colorati.

  • Aggiungi una emission map: una terza texture il cui colore viene sommato al risultato senza tener conto dell'illuminazione, in modo che alcune parti dell'oggetto sembrino brillare.
    Mostra la soluzione

    Collega una terza texture e somma il suo colore dopo l'illuminazione, senza moltiplicarlo per alcun termine della luce.

    float3 emission = emissionMap.sample(mapSampler, in.uv).rgb;
return float4(ambient + diffuse + specular + emission, 1.0);

    Per evitare che il telaio d'acciaio brilli, moltiplica l'emissione per 1.0 - step(0.01, specularColor.r), così compare solo dove la specular map è nera.
