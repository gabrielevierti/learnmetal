Più luci#

Progetto di esempio examples/Sources/10-MultipleLights, si esegue con swift run MultipleLights. Scarica tutti gli esempi oppure guarda come eseguirli.

È raro che una scena abbia una luce sola.
Questo capitolo mette insieme tutta la sezione sull'illuminazione: una luce direzionale, quattro luci puntiformi e una torcia, tutte in un'unica fragment function.
Il trucco sta nell'organizzazione: una funzione per ogni tipo di luce, e i risultati sommati.

Funzioni negli shader#

MSL è C++, quindi le normali funzioni di supporto funzionano.
Tutto ciò che non è marcato vertex, fragment o kernel è una funzione qualunque che puoi chiamare.
Marca le funzioni di supporto come static, così restano private al file.

struct Surface {
    float3 position;
    float3 normal;
    float3 viewDir;
    float3 albedo;
    float3 specular;
    float shininess;
};

static float3 calcDirectionalLight(DirectionalLight light, Surface s) {
    float3 lightDir = normalize(-light.direction);
    float diff = max(dot(s.normal, lightDir), 0.0);
    float spec = pow(max(dot(s.viewDir, reflect(-lightDir, s.normal)), 0.0), s.shininess);

    return light.ambient * s.albedo
         + light.diffuse * diff * s.albedo
         + light.specular * spec * s.specular;
}

static float3 calcPointLight(PointLight light, Surface s) {
    float3 toLight = light.position - s.position;
    float distance = length(toLight);
    float3 lightDir = toLight / distance;

    float diff = max(dot(s.normal, lightDir), 0.0);
    float spec = pow(max(dot(s.viewDir, reflect(-lightDir, s.normal)), 0.0), s.shininess);
    float attenuation = 1.0 / (light.constantTerm
                             + light.linearTerm * distance
                             + light.quadraticTerm * distance * distance);

    return (light.ambient * s.albedo
          + light.diffuse * diff * s.albedo
          + light.specular * spec * s.specular) * attenuation;
}

calcSpotLight è la funzione della luce puntiforme con l'intensità del cono del capitolo precedente moltiplicata nei termini diffuse e specular.

Raccogliere le proprietà della superficie in una struct Surface tiene corte le liste dei parametri e fa sì che le texture vengano lette una volta sola, e non una volta per luce.

Array negli uniform#

Un array di dimensione fissa dentro la struct degli uniform contiene le luci puntiformi:

#define POINT_LIGHT_COUNT 4

struct FragmentUniforms {
    DirectionalLight directionalLight;
    PointLight pointLights[POINT_LIGHT_COUNT];
    SpotLight spotLight;
    float3 viewPosition;
    float shininess;
};

fragment float4 fragment_main(VertexOut in [[stage_in]],
                              constant FragmentUniforms &uniforms [[buffer(1)]],
                              texture2d<float> diffuseMap  [[texture(0)]],
                              texture2d<float> specularMap [[texture(1)]],
                              sampler mapSampler [[sampler(0)]]) {
    Surface s;
    s.position = in.worldPosition;
    s.normal = normalize(in.normal);
    s.viewDir = normalize(uniforms.viewPosition - in.worldPosition);
    s.albedo = diffuseMap.sample(mapSampler, in.uv).rgb;
    s.specular = specularMap.sample(mapSampler, in.uv).rgb;
    s.shininess = uniforms.shininess;

    float3 color = calcDirectionalLight(uniforms.directionalLight, s);
    for (int i = 0; i < POINT_LIGHT_COUNT; i++) {
        color += calcPointLight(uniforms.pointLights[i], s);
    }
    color += calcSpotLight(uniforms.spotLight, s);

    return float4(color, 1.0);
}

Il lato Swift#

Swift non ha array C di dimensione fissa nelle struct, ma una tupla di elementi identici ha lo stesso layout in memoria:

struct FragmentUniforms {
    var directionalLight: DirectionalLight
    var pointLights: (PointLight, PointLight, PointLight, PointLight)
    var spotLight: SpotLight
    var viewPosition: Float3
    var shininess: Float
}

// C++ has real fixed-size arrays, so the layout matches the shader directly.
struct FragmentUniforms {
    DirectionalLight directionalLight;
    PointLight pointLights[4];
    SpotLight spotLight;
    simd::float3 viewPosition;
    float shininess;
};

Con numeri più grandi diventa scomodo.
L'alternativa che scala è mettere le luci in un loro MTLBuffer e passare un puntatore più un conteggio:

fragment float4 fragment_main(VertexOut in [[stage_in]],
                              constant FragmentUniforms &uniforms [[buffer(1)]],
                              constant PointLight *pointLights [[buffer(2)]],
                              ...) {
    for (uint i = 0; i < uniforms.pointLightCount; i++) {
        color += calcPointLight(pointLights[i], s);
    }

let lightBuffer = device.makeBuffer(bytes: pointLights,
                                    length: MemoryLayout<PointLight>.stride * pointLights.count,
                                    options: [])!
encoder.setFragmentBuffer(lightBuffer, offset: 0, index: 2)

// pointLights is a std::vector<PointLight>
MTL::Buffer* lightBuffer = device->newBuffer(pointLights.data(),
                                             sizeof(PointLight) * pointLights.size(),
                                             MTL::ResourceStorageModeShared);
encoder->setFragmentBuffer(lightBuffer, 0, 2);      // buffer, offset, index

Un buffer collegato a uno shader è soltanto memoria, e un parametro puntatore permette allo shader di indicizzarlo come un array di qualsiasi lunghezza.
È molto più flessibile degli array di uniform delle API più vecchie, ed è la forma che useremo da adesso.

Il costo di molte luci#

Ogni fragment valuta ogni luce, quindi il costo è fragment × luci.
Una manciata va bene.
Centinaia no, e risolvere questo problema è lo scopo del Deferred shading, più avanti.

Esercizi#

  • Ricrea atmosfere diverse cambiando solo i colori delle luci e il colore di sfondo: un deserto a mezzogiorno, una fabbrica in penombra, un corridoio horror illuminato dalla sola torcia.
    Mostra la soluzione

    Deserto: una luce direzionale forte e calda (1.0, 0.95, 0.8), un colore di sfondo chiaro color sabbia e le luci puntiformi quasi spente.
    Fabbrica: una luce direzionale debole e fredda, luci puntiformi bluastre a corta portata, uno sfondo grigio-blu scuro.
    Horror: sfondo nero, luce direzionale a circa 0.02, luci puntiformi spente o rosso cupo, e solo lo spot a piena intensità.

  • Muovi le luci nel tempo riscrivendo a ogni frame il contenuto del buffer attraverso lightBuffer.contents().
    Mostra la soluzione

    Ottieni un puntatore tipizzato alla memoria del buffer e scrivi i nuovi valori prima di codificare il frame.
    In Swift: let lights = lightBuffer.contents().bindMemory(to: PointLight.self, capacity: count) e poi lights[i].position = ....
    In C++: auto* lights = static_cast<PointLight*>(lightBuffer->contents());.
    Quando la GPU potrebbe stare ancora leggendo il frame precedente, usa l'anello di buffer del capitolo Dati avanzati.
