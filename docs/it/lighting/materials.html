Materiali#

Progetto di esempio examples/Sources/08-BasicLighting, si esegue con swift run BasicLighting. Scarica tutti gli esempi oppure guarda come eseguirli.

Acciaio, legno e plastica reagiscono in modo diverso alla stessa luce.
Per descriverlo smettiamo di usare un unico colore dell'oggetto e diamo a ogni superficie un materiale: colori separati per i tre termini di Phong, più una shininess.

Le struct del materiale e della luce#

Le struct di MSL si possono annidare, e questo tiene leggibili gli uniform:

struct Material {
    float3 ambient;
    float3 diffuse;
    float3 specular;
    float shininess;
};

struct Light {
    float3 position;
    float3 ambient;
    float3 diffuse;
    float3 specular;
};

struct FragmentUniforms {
    Material material;
    Light light;
    float3 viewPosition;
};
  • ambient è il colore che la superficie mostra sotto la luce ambient, di solito uguale al suo colore diffuse.
  • diffuse è il colore principale della superficie.
  • specular è il colore del suo riflesso.
  • shininess controlla quanto è stretto il riflesso.

Anche la luce ha le proprie intensità per ogni termine.
La luce ambient deve essere debole, quella diffuse è il vero colore della luce, e quella specular di solito è bianco pieno.

Lo shader#

fragment float4 fragment_main(VertexOut in [[stage_in]],
                              constant FragmentUniforms &uniforms [[buffer(1)]]) {
    Material material = uniforms.material;
    Light light = uniforms.light;

    float3 normal = normalize(in.normal);
    float3 lightDir = normalize(light.position - in.worldPosition);
    float3 viewDir = normalize(uniforms.viewPosition - in.worldPosition);
    float3 reflectDir = reflect(-lightDir, normal);

    float3 ambient = light.ambient * material.ambient;

    float diff = max(dot(normal, lightDir), 0.0);
    float3 diffuse = light.diffuse * (diff * material.diffuse);

    float spec = pow(max(dot(viewDir, reflectDir), 0.0), material.shininess);
    float3 specular = light.specular * (spec * material.specular);

    return float4(ambient + diffuse + specular, 1.0);
}

Il lato Swift#

Rispecchia le struct con esattezza, con i membri nello stesso ordine:

struct Material {
    var ambient: Float3
    var diffuse: Float3
    var specular: Float3
    var shininess: Float
}

struct Light {
    var position: Float3
    var ambient: Float3
    var diffuse: Float3
    var specular: Float3
}

struct FragmentUniforms {
    var material: Material
    var light: Light
    var viewPosition: Float3
}

struct Material {
    simd::float3 ambient;
    simd::float3 diffuse;
    simd::float3 specular;
    float shininess;
};

struct Light {
    simd::float3 position;
    simd::float3 ambient;
    simd::float3 diffuse;
    simd::float3 specular;
};

struct FragmentUniforms {
    Material material;
    Light light;
    simd::float3 viewPosition;
};

var fragmentUniforms = FragmentUniforms(
    material: Material(ambient: [1.0, 0.5, 0.31],
                       diffuse: [1.0, 0.5, 0.31],
                       specular: [0.5, 0.5, 0.5],
                       shininess: 32),
    light: Light(position: lightPosition,
                 ambient: [0.2, 0.2, 0.2],
                 diffuse: [0.5, 0.5, 0.5],
                 specular: [1, 1, 1]),
    viewPosition: camera.position)

FragmentUniforms fragmentUniforms{
    Material{ {1.0f, 0.5f, 0.31f},     // ambient
              {1.0f, 0.5f, 0.31f},     // diffuse
              {0.5f, 0.5f, 0.5f},      // specular
              32.0f },                 // shininess
    Light{ lightPosition,
           {0.2f, 0.2f, 0.2f},         // ambient
           {0.5f, 0.5f, 0.5f},         // diffuse
           {1.0f, 1.0f, 1.0f} },       // specular
    camera.position
};

Controlla il layout

Material finisce con un Float isolato dopo tre vettori da 16 byte, quindi la sua size è 52 byte e il suo stride è 64.
Qui il membro successivo, light, è allineato a 16 byte e comincia all'offset 64 in entrambi i linguaggi.
Con le struct annidate c'è una trappola: Swift può mettere un piccolo membro successivo, per esempio un Float, nella coda inutilizzata della struct precedente (all'offset 52), mentre MSL non lo fa mai.
Per stare tranquillo, fai seguire a una struct annidata un membro allineato a 16 byte, oppure fai finire ogni struct annidata su un multiplo di 16 byte.
Quando i valori sembrano sbagliati, stampa MemoryLayout<FragmentUniforms>.offset(of: \.viewPosition) e confronta gli offset a mano.

Giocare con i colori della luce#

Poiché la luce ha termini separati, cambiare la luce cambia tutta l'atmosfera:

let lightColor = Float3(sin(time * 2.0), sin(time * 0.7), sin(time * 1.3)) * 0.5 + 0.5
fragmentUniforms.light.diffuse = lightColor * 0.5
fragmentUniforms.light.ambient = lightColor * 0.1

simd::float3 lightColor = simd::float3{std::sin(time * 2.0f), std::sin(time * 0.7f), std::sin(time * 1.3f)} * 0.5f + 0.5f;
fragmentUniforms.light.diffuse = lightColor * 0.5f;
fragmentUniforms.light.ambient = lightColor * 0.1f;

Esercizi#

  • Riproduci ogni materiale della tabella.
    Mostra la soluzione

    Copia i quattro valori di una riga nell'uniform del materiale e imposta a bianco ambient, diffuse e specular della luce.
    La demo interattiva qui sopra ha i preset; passa dall'uno all'altro e confronta quanto è largo e quanto è colorato il riflesso.

  • Perché un metallo risulta più convincente quando il suo colore specular coincide con il suo colore diffuse?
    Mostra la soluzione

    Un metallo non ha una riflessione diffusa propria.
    Tutta la luce che restituisce viene riflessa in superficie, e quel riflesso prende la tinta del metallo: l'oro riflette luce gialla.
    Quindi il suo riflesso ha il colore del metallo.
    Il riflesso di una plastica viene dal suo strato esterno trasparente e resta bianco, qualunque sia il colore sotto.
    È l'idea che più avanti la sezione PBR rende precisa con il parametro metalness.
