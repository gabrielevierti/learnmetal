PBR

Illuminazione#

Progetto di esempio examples/Sources/16-PBR, si esegue con swift run PBR. Scarica tutti gli esempi oppure guarda come eseguirli.

Con la teoria alle spalle, lo shader PBR è breve.
Questo capitolo implementa la BRDF di Cook-Torrance per le luci puntiformi, prima con valori di materiale costanti e poi con le texture.

Le funzioni della BRDF#

Ogni formula del capitolo precedente diventa una piccola funzione:

constant float PI = 3.14159265359;

static float distributionGGX(float3 N, float3 H, float roughness) {
    float a = roughness * roughness;
    float a2 = a * a;
    float NdotH = max(dot(N, H), 0.0);
    float denom = NdotH * NdotH * (a2 - 1.0) + 1.0;
    return a2 / (PI * denom * denom);
}

static float geometrySchlickGGX(float NdotV, float roughness) {
    float r = roughness + 1.0;
    float k = (r * r) / 8.0;
    return NdotV / (NdotV * (1.0 - k) + k);
}

static float geometrySmith(float3 N, float3 V, float3 L, float roughness) {
    float NdotV = max(dot(N, V), 0.0);
    float NdotL = max(dot(N, L), 0.0);
    return geometrySchlickGGX(NdotV, roughness) * geometrySchlickGGX(NdotL, roughness);
}

static float3 fresnelSchlick(float cosTheta, float3 F0) {
    return F0 + (1.0 - F0) * pow(saturate(1.0 - cosTheta), 5.0);
}

Elevare al quadrato la roughness prima di usarla (a = roughness²) fa percepire il parametro come lineare agli artisti.
È una convenzione adottata da quasi tutti i motori.

La fragment function#

struct PBRUniforms {
    float3 viewPosition;
    float3 albedo;
    float metallic;
    float roughness;
    float ao;
    uint lightCount;
};

struct PBRLight {
    float3 position;
    float3 color;      // radiant intensity, can be far above 1
};

fragment float4 fragment_pbr(VertexOut in [[stage_in]],
                             constant PBRUniforms &uniforms [[buffer(1)]],
                             constant PBRLight *lights [[buffer(2)]]) {
    float3 N = normalize(in.normal);
    float3 V = normalize(uniforms.viewPosition - in.worldPosition);

    float3 albedo = uniforms.albedo;
    float metallic = uniforms.metallic;
    float roughness = uniforms.roughness;

    float3 F0 = mix(float3(0.04), albedo, metallic);

    float3 Lo = float3(0.0);
    for (uint i = 0; i < uniforms.lightCount; i++) {
        float3 toLight = lights[i].position - in.worldPosition;
        float distance = length(toLight);
        float3 L = toLight / distance;
        float3 H = normalize(V + L);

        float3 radiance = lights[i].color / (distance * distance);

        float D = distributionGGX(N, H, roughness);
        float G = geometrySmith(N, V, L, roughness);
        float3 F = fresnelSchlick(max(dot(H, V), 0.0), F0);

        float NdotL = max(dot(N, L), 0.0);
        float3 specular = (D * G * F) / (4.0 * max(dot(N, V), 0.0) * NdotL + 0.0001);

        float3 kD = (1.0 - F) * (1.0 - metallic);

        Lo += (kD * albedo / PI + specular) * radiance * NdotL;
    }

    float3 ambient = float3(0.03) * albedo * uniforms.ao;
    return float4(ambient + Lo, 1.0);
}

Ripercorriamo il ciclo:

  • La radianza è il colore della luce attenuato dall'inverso del quadrato della distanza.
    Una luce puntiforme consegna tutta la sua energia da una sola direzione, quindi l'integrale dell'equazione della riflettanza si riduce a una valutazione per luce.
  • F0 passa dal valore dei dielettrici, 0.04, all'albedo man mano che il materiale diventa metallico.
  • Il termine specular è D·G·F diviso per il fattore di normalizzazione.
    La piccola costante evita una divisione per zero.
  • kD toglie la frazione riflessa ed elimina del tutto il diffuse per i metalli.
  • Il risultato viene moltiplicato per NdotL, il fattore coseno.

L'uscita è HDR lineare.
Passa attraverso il pass di tone mapping del capitolo HDR e il drawable sRGB.
Non applicare la correzione gamma in questo shader.

Il termine ambient fisso è un segnaposto.
Sostituirlo con la vera luce dell'ambiente è il compito dei prossimi due capitoli.

Una griglia di sfere#

La prova standard: una griglia di sfere in cui la metalness cresce dal basso verso l'alto e la roughness da sinistra a destra.
La sfera la genera Model I/O:

let sphere = MDLMesh(sphereWithExtent: [1, 1, 1], segments: [64, 64],
                     inwardNormals: false, geometryType: .triangles, allocator: allocator)
sphere.vertexDescriptor = mdlDescriptor
sphereMesh = try MTKMesh(mesh: sphere, device: device)

// makeSphere() from the Model I/O chapter, drawn without an index buffer.
std::vector<MeshVertex> sphere = makeSphere(0.5f, 64);
sphereBuffer = device->newBuffer(sphere.data(), sizeof(MeshVertex) * sphere.size(),
                                 MTL::ResourceStorageModeShared);
sphereVertexCount = sphere.size();

let rows = 7, columns = 7
for row in 0..<rows {
    pbrUniforms.metallic = Float(row) / Float(rows - 1)
    for column in 0..<columns {
        // A roughness of exactly 0 gives an infinitely small highlight; clamp it.
        pbrUniforms.roughness = max(Float(column) / Float(columns - 1), 0.05)
        uniforms.model = float4x4(translation: [Float(column - columns / 2) * 2.5,
                                                Float(row - rows / 2) * 2.5, 0])
        // set uniforms, draw the sphere
    }
}

const int rows = 7, columns = 7;
for (int row = 0; row < rows; row++) {
    pbrUniforms.metallic = float(row) / float(rows - 1);
    for (int column = 0; column < columns; column++) {
        // A roughness of exactly 0 gives an infinitely small highlight; clamp it.
        pbrUniforms.roughness = std::max(float(column) / float(columns - 1), 0.05f);
        uniforms.model = translation(simd::float3{float(column - columns / 2) * 2.5f,
                                                  float(row - rows / 2) * 2.5f, 0});
        // set uniforms, draw the sphere
    }
}

Quattro luci di colore (300, 300, 300) messe a circa 10 unità davanti alla griglia la illuminano bene.
Valori così grandi sono normali con il calo secondo l'inverso del quadrato.

Anche con un termine ambient piatto il risultato colpisce: i dielettrici ruvidi sembrano gesso o gomma, quelli lisci plastica, e i metalli hanno riflessi stretti e colorati.

PBR con le texture#

Sostituisci le costanti con letture da texture, e usa la funzione di normal mapping di Normal mapping:

fragment float4 fragment_pbr(VertexOut in [[stage_in]],
                             constant PBRUniforms &uniforms [[buffer(1)]],
                             constant PBRLight *lights [[buffer(2)]],
                             texture2d<float> albedoMap    [[texture(0)]],
                             texture2d<float> normalMap    [[texture(1)]],
                             texture2d<float> metallicMap  [[texture(2)]],
                             texture2d<float> roughnessMap [[texture(3)]],
                             texture2d<float> aoMap        [[texture(4)]],
                             sampler s [[sampler(0)]]) {
    float3 albedo = albedoMap.sample(s, in.uv).rgb;
    float metallic = metallicMap.sample(s, in.uv).r;
    float roughness = roughnessMap.sample(s, in.uv).r;
    float ao = aoMap.sample(s, in.uv).r;
    float3 N = perturbedNormal(in, normalMap, s);
    ...
}

Carica la mappa dell'albedo come sRGB e tutte le altre come dati lineari.
Molti pacchetti di asset riuniscono occlusion, roughness e metalness nei canali rosso, verde e blu di un'unica texture "ORM", risparmiando due letture.

Con Model I/O estendi il loader dei materiali del capitolo Mesh perché legga i semantic .metallic, .roughness, .tangentSpaceNormal e .ambientOcclusion, ripiegando su texture da 1 × 1 con i valori scalari quando una proprietà non ha texture.

Esercizi#

  • Dai a ogni sfera la stessa roughness e varia solo l'albedo per vedere come i metalli colorano i loro riflessi.
    Mostra la soluzione

    Imposta la roughness a una costante, per esempio 0.3, e ricava l'albedo dalla colonna.
    I dielettrici mantengono un riflesso bianco qualunque sia il loro colore.
    Al crescere della metalness il riflesso prende il colore dell'albedo, perché F0 diventa l'albedo stesso.

  • Trova un set gratuito di materiali PBR, come ferro arrugginito o plastica consumata, e applicalo a una sfera.
    Mostra la soluzione

    Siti come Poly Haven e ambientCG pubblicano set gratuiti.
    Carica l'albedo come sRGB e le mappe normal, roughness, metalness e occlusion come lineari, aggiungi le tangenti alla mesh e usa la fragment function con texture di questo capitolo.
