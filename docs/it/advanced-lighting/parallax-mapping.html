Illuminazione avanzata

Parallax mapping#

Il normal mapping cambia il modo in cui una superficie è illuminata, ma non che cosa vedi e dove.
Con un angolo radente un muro di mattoni con normal map sembra ancora una tavola dipinta, perché i mattoni non nascondono la malta che sta dietro.
Il parallax mapping sposta le coordinate di texture in base a una height map e all'angolo di vista, così le parti alte sembrano coprire quelle basse.

L'idea#

Accanto alle mappe di colore e delle normali ci serve una height map, una texture in scala di grigi che descrive il rilievo della superficie.
È più comodo salvare la profondità, l'inverso dell'altezza: 0 sulla superficie superiore, 1 nel punto più profondo.

Immagina chi guarda mentre osserva un punto A sul poligono piatto.
Sulla superficie vera, quella con i rilievi, la linea di vista avrebbe colpito il rilievo prima, in un punto B, e chi guarda dovrebbe vedere la texture in B. Il parallax mapping stima di quanto far scivolare la coordinata di texture da A verso B.

Tutto questo si fa in spazio tangente, dove la superficie è il piano xy e le u e v della texture corrono lungo x e y. La direzione di vista va quindi convertita prima in spazio tangente.

La direzione di vista in spazio tangente#

La matrice TBN del capitolo precedente converte da tangente a mondo.
La sua trasposta fa il contrario, perché la matrice è ortonormale:

float3x3 TBN = float3x3(T, B, N);
float3 viewDirTangent = normalize(transpose(TBN) * (uniforms.viewPosition - in.worldPosition));

Parallax mapping semplice#

Leggi la profondità alla coordinata attuale e spostati lungo la direzione di vista di quella quantità:

static float2 parallaxSimple(float2 uv, float3 viewDir,
                             texture2d<float> depthMap, sampler s, float scale) {
    float depth = depthMap.sample(s, uv).r;
    float2 offset = viewDir.xy / viewDir.z * (depth * scale);
    return uv - offset;
}

scale controlla l'intensità; sono tipici valori tra 0.05 e 0.1.
La divisione per viewDir.z rende lo spostamento più grande agli angoli radenti.
Poi usa la coordinata spostata per ogni lettura di texture del fragment: colore, normale, specular.

float2 uv = parallaxSimple(in.uv, viewDirTangent, depthMap, s, 0.1);
if (uv.x < 0.0 || uv.x > 1.0 || uv.y < 0.0 || uv.y > 1.0) {
    discard_fragment();
}
float3 albedo = diffuseMap.sample(s, uv).rgb;
float3 tangentNormal = normalMap.sample(s, uv).xyz * 2.0 - 1.0;

Il discard rifila i bordi di un rettangolo singolo, dove le coordinate spostate uscirebbero dalla texture.
Sulle superfici che si ripetono lo lasceresti fuori.

Convenzioni di segno

Se lo spostamento vada sottratto o sommato, e se la sua y vada cambiata di segno, dipende dalla direzione del tuo asse v e della bitangente.
Se l'effetto sembra gonfiarsi verso l'interno o scivolare nel verso sbagliato quando muovi la camera, inverti il segno della componente y.

Questa versione a una sola lettura funziona per i rilievi dolci.
Sui cambi di altezza ripidi o ad angoli molto bassi la stima è scarsa e la superficie sembra galleggiare.

Steep parallax mapping#

Una stima migliore si ottiene avanzando lungo il raggio di vista a piccoli passi, attraverso un certo numero di strati di profondità, finché il raggio scende sotto la superficie:

static float2 parallaxSteep(float2 uv, float3 viewDir,
                            texture2d<float> depthMap, sampler s, float scale) {
    float layerCount = mix(32.0, 8.0, abs(viewDir.z));   // more layers at shallow angles
    float layerDepth = 1.0 / layerCount;
    float2 deltaUV = viewDir.xy / viewDir.z * scale / layerCount;

    float2 currentUV = uv;
    float currentLayerDepth = 0.0;
    float mapDepth = depthMap.sample(s, currentUV, level(0)).r;

    while (currentLayerDepth < mapDepth) {
        currentUV -= deltaUV;
        mapDepth = depthMap.sample(s, currentUV, level(0)).r;
        currentLayerDepth += layerDepth;
    }
    return currentUV;
}

Dentro un ciclo la GPU non riesce a calcolare in modo affidabile i livelli di mip automatici, quindi le letture indicano esplicitamente il livello 0.
Il risultato è molto più convincente, ma gli strati discreti si notano come gradini.

Parallax occlusion mapping#

I gradini spariscono se, invece di prendere il primo strato sotto la superficie, interpoliamo tra l'ultimo punto sopra la superficie e il primo sotto:

    // ...after the loop in parallaxSteep
    float2 previousUV = currentUV + deltaUV;

    float afterDepth  = mapDepth - currentLayerDepth;
    float beforeDepth = depthMap.sample(s, previousUV, level(0)).r - currentLayerDepth + layerDepth;

    float weight = afterDepth / (afterDepth - beforeDepth);
    return mix(currentUV, previousUV, weight);

È il parallax occlusion mapping (POM).
Le due profondità ci dicono quanto dista ciascun punto dalla superficie vera, e una miscela lineare cade molto vicino all'intersezione reale.

I limiti#

  • È un'illusione dentro il poligono.
    Il profilo resta piatto, e l'effetto si rompe agli angoli radenti.
  • Costa caro: decine di letture di texture per fragment.
    Riduci il numero di strati con la distanza.
  • Il rilievo non proietta ombre su sé stesso, a meno di far avanzare un secondo raggio verso la luce.

Quando ti serve geometria vera, con profili e ombre veri, sposta i vertici con la tassellazione.

Esercizi#

  • Passa da una variante all'altra con un uniform e confrontale con un angolo di vista basso.
    Mostra la soluzione

    Aggiungi un uniform intero e scegli in base a quello quando calcoli la coordinata di texture.
    Ad angolo basso la versione semplice galleggia e si deforma, la versione steep è stabile ma mostra gradini a strati sui pendii, e l'occlusion mapping elimina i gradini.

  • Implementa l'auto-ombreggiatura avanzando in spazio tangente dal punto trovato verso la luce.
    Mostra la soluzione

    Dalla coordinata di texture e dalla profondità finali avanza verso la luce in spazio tangente.
    Se a un qualsiasi passo la height map sale sopra il raggio, il punto è in ombra.

    float3 lightDir = normalize(transpose(TBN) * (uniforms.lightPosition - in.worldPosition));
float2 stepUV = float2(lightDir.x, -lightDir.y) / lightDir.z * uniforms.heightScale / 16.0;
float rayDepth = mapDepth;
float lit = 1.0;
for (int i = 0; i < 16; i++) {
    uv += stepUV;
    rayDepth -= mapDepth / 16.0;
    if (depthMap.sample(s, uv, level(0.0)).r < rayDepth) { lit = 0.3; break; }
}
