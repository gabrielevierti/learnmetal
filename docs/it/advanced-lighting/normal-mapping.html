Illuminazione avanzata

Normal mapping#

Un muro di mattoni disegnato come un rettangolo piatto sembra piatto, per quanto sia buona la texture.
Lo tradisce l'illuminazione, perché ogni fragment ha la stessa normale.
Il normal mapping salva una normale diversa per ogni texel, così la luce reagisce a rilievi e scanalature che nella geometria non esistono.

Le normal map#

Una normale è un vettore con componenti da -1 a 1.
Salvata in un'immagine, ogni componente viene riportata nell'intervallo da 0 a 1, e lo shader fa l'operazione inversa:

float3 normal = normalMap.sample(s, in.uv).xyz * 2.0 - 1.0;

Le normal map appaiono bluastre perché la maggior parte delle normali punta dritta fuori dalla superficie, lungo +z, che viene salvato come il colore (0.5, 0.5, 1.0).
Carica le normal map come dati lineari, mai come sRGB.

Lo spazio tangente#

Le normali della mappa sono espresse rispetto alla superficie stessa, in spazio tangente, dove +z punta fuori dalla superficie.
È questo che rende una mappa utilizzabile su un muro rivolto in qualsiasi direzione, o avvolta intorno a un modello curvo.
Per usarle nei calcoli della luce ci serve un modo di ruotarle dallo spazio tangente allo spazio mondo.

Quella rotazione è la matrice TBN, costruita con tre vettori unitari perpendicolari in ogni vertice:

  • N, la normale del vertice,
  • T, la tangente, che corre lungo la superficie nella direzione in cui u cresce,
  • B, la bitangente, che corre lungo la superficie nella direzione in cui v cresce.

Ottenere le tangenti#

Le tangenti si calcolano dalle posizioni e dalle coordinate di texture.
Model I/O lo fa per te.
Aggiungi al vertex descriptor un attributo per la tangente e chiedi la base dopo il caricamento:

vertexDescriptor.attributes[3].format = .float3   // tangent
vertexDescriptor.attributes[3].offset = 32
vertexDescriptor.layouts[0].stride = 44

(mdlDescriptor.attributes[3] as! MDLVertexAttribute).name = MDLVertexAttributeTangent

// Add a tangent to the vertex struct from Model Loading.
struct MeshVertex {
    float position[3];
    float normal[3];
    float uv[2];
    float tangent[3];
};

vertexDescriptor->attributes()->object(3)->setFormat(MTL::VertexFormatFloat3);   // tangent
vertexDescriptor->attributes()->object(3)->setOffset(offsetof(MeshVertex, tangent));
vertexDescriptor->layouts()->object(0)->setStride(sizeof(MeshVertex));           // 44 bytes

mesh.addOrthTanBasis(forTextureCoordinateAttributeNamed: MDLVertexAttributeTextureCoordinate,
                     normalAttributeNamed: MDLVertexAttributeNormal,
                     tangentAttributeNamed: MDLVertexAttributeTangent)
mesh.vertexDescriptor = mdlDescriptor

// Without Model I/O, compute one tangent per triangle and store it in its three vertices.
for (size_t i = 0; i + 2 < vertices.size(); i += 3) {
    MeshVertex& a = vertices[i]; MeshVertex& b = vertices[i + 1]; MeshVertex& c = vertices[i + 2];
    simd::float3 e1 = {b.position[0] - a.position[0], b.position[1] - a.position[1], b.position[2] - a.position[2]};
    simd::float3 e2 = {c.position[0] - a.position[0], c.position[1] - a.position[1], c.position[2] - a.position[2]};
    float du1 = b.uv[0] - a.uv[0], dv1 = b.uv[1] - a.uv[1];
    float du2 = c.uv[0] - a.uv[0], dv2 = c.uv[1] - a.uv[1];

    float f = 1.0f / (du1 * dv2 - du2 * dv1);
    simd::float3 tangent = simd::normalize(f * (dv2 * e1 - dv1 * e2));
    for (MeshVertex* v : {&a, &b, &c}) {
        v->tangent[0] = tangent.x; v->tangent[1] = tangent.y; v->tangent[2] = tangent.z;
    }
}

Assegnare di nuovo il descriptor fa sì che Model I/O ricomponga i buffer con il nuovo attributo.

Per la geometria costruita a mano, la tangente di un triangolo con lati e1, e2 e differenze di coordinate di texture (du1, dv1), (du2, dv2) è:

let f = 1 / (du1 * dv2 - du2 * dv1)
let tangent = normalize(f * (dv2 * e1 - dv1 * e2))

float f = 1.0f / (du1 * dv2 - du2 * dv1);
simd::float3 tangent = simd::normalize(f * (dv2 * e1 - dv1 * e2));

Lo shader#

La vertex function porta la normale e la tangente in spazio mondo:

struct VertexIn {
    float3 position [[attribute(0)]];
    float3 normal   [[attribute(1)]];
    float2 uv       [[attribute(2)]];
    float3 tangent  [[attribute(3)]];
};

struct VertexOut {
    float4 position [[position]];
    float3 worldPosition;
    float3 normal;
    float3 tangent;
    float2 uv;
};

vertex VertexOut vertex_main(VertexIn in [[stage_in]],
                             constant Uniforms &uniforms [[buffer(1)]]) {
    VertexOut out;
    float4 world = uniforms.model * float4(in.position, 1.0);
    out.position = uniforms.projection * uniforms.view * world;
    out.worldPosition = world.xyz;
    out.normal = uniforms.normalMatrix * in.normal;
    out.tangent = uniforms.normalMatrix * in.tangent;
    out.uv = in.uv;
    return out;
}

La fragment function ricostruisce una base esattamente perpendicolare, poi ruota con essa la normale letta:

static float3 perturbedNormal(VertexOut in, texture2d<float> normalMap, sampler s) {
    float3 N = normalize(in.normal);
    float3 T = normalize(in.tangent);
    T = normalize(T - dot(T, N) * N);     // Gram-Schmidt: make T perpendicular to N
    float3 B = cross(N, T);

    float3 tangentNormal = normalMap.sample(s, in.uv).xyz * 2.0 - 1.0;
    float3x3 TBN = float3x3(T, B, N);
    return normalize(TBN * tangentNormal);
}

float3x3(T, B, N) costruisce una matrice con quei vettori come colonne, quindi la moltiplicazione porta un vettore dallo spazio tangente allo spazio mondo.
Usa la normale restituita al posto di normalize(in.normal) in tutto il codice di illuminazione.
Non cambia nient'altro.

Il canale verde e la mano#

Due cose fanno spesso apparire "rivoltata" una superficie con normal map, con i rilievi illuminati come incavi:

  • La convenzione della normal map.
    Le mappe esistono in due varianti che differiscono per il segno del canale verde, di solito etichettate OpenGL (+Y) e DirectX (-Y).
    Quale sia quella giusta dipende dal verso della tua coordinata v e della bitangente.
    Se i rilievi appaiono invertiti, cambia segno a tangentNormal.y.
  • Coordinate di texture specchiate.
    I modelli simmetrici spesso specchiano le loro UV, cosa che inverte la bitangente su una metà.
    Gli esportatori lo codificano come un segno nella quarta componente della tangente.
    Se ti serve gestirlo, Model I/O offre addTangentBasis(forTextureCoordinateAttributeNamed:tangentAttributeNamed:bitangentAttributeNamed:) per salvare una bitangente esplicita.

Un controllo rapido per qualsiasi modello: manda in uscita come colore N * 0.5 + 0.5.
Colori pastello che cambiano con dolcezza significano che la base è sana.

Normal map a due canali#

Poiché la z di una normale unitaria si può ricalcolare da x e y, le normal map vengono spesso salvate con due canali in un formato compresso, per esempio BC5 sui Mac o EAC RG11 e ASTC sulle GPU Apple:

float2 xy = normalMap.sample(s, in.uv).rg * 2.0 - 1.0;
float3 tangentNormal = float3(xy, sqrt(saturate(1.0 - dot(xy, xy))));

Esercizi#

  • Fai ruotare nel tempo un rettangolo con normal map e verifica che l'illuminazione resti coerente con una luce fissa.
    Mostra la soluzione

    Poiché la normale e la tangente vengono trasformate con la matrice delle normali, la base TBN ruota insieme al rettangolo e le normali lette finiscono in spazio mondo.
    Con una luce fissa il lato chiaro di ogni mattone deve restare dalla parte rivolta verso la luce mentre il rettangolo gira.
    Se invece l'ombreggiatura ruota con il rettangolo, la tangente non viene trasformata.

  • Scala x e y della normale in spazio tangente con un uniform di "intensità del rilievo" prima di normalizzare.
    Mostra la soluzione

    Scala prima di normalizzare.
    La demo interattiva lo offre come slider.

    float3 tangentNormal = normalMap.sample(s, in.uv).xyz * 2.0 - 1.0;
tangentNormal.xy *= uniforms.strength;      // 0 is flat, above 1 exaggerates
float3 N = normalize(TBN * tangentNormal);
