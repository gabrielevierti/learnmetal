Illuminazione avanzata

SSAO#

Il nostro termine ambient è una costante, quindi angoli, pieghe e spazi tra gli oggetti sono luminosi quanto le superfici aperte.
Nella realtà questi punti ricevono meno luce indiretta, perché la geometria vicina ne blocca una parte.
L'effetto si chiama ambient occlusion, e aggiungerlo dà alla scena la profondità e il contatto che la luce ambient piatta non ha.

Calcolare la vera occlusione richiede di tracciare raggi contro la scena.
La screen-space ambient occlusion (SSAO) la approssima usando solo ciò che è già a schermo: il depth buffer.

Come funziona#

Per ogni pixel prendi un certo numero di punti in un piccolo emisfero sopra la superficie, orientato lungo la normale.
Per ogni punto controlla il G-buffer: c'è geometria davanti a quel punto?
La frazione di punti bloccati è l'occlusione del pixel.

L'SSAO si inserisce in modo naturale dopo un pass di G-buffer.
Ha bisogno di posizioni e normali in spazio vista, quindi o le salvi così o le trasformi in lettura.
Lavorare in spazio vista riduce i confronti di profondità a un confronto tra z.

Il kernel di campioni#

Genera 64 punti casuali dentro un emisfero unitario rivolto lungo +z, in spazio tangente.
Scalali in modo che ne cadano di più vicino all'origine, perché ciò che occlude da vicino conta di più:

var kernel: [SIMD4<Float>] = (0..<64).map { i in
    var sample = Float3(.random(in: -1...1), .random(in: -1...1), .random(in: 0...1))
    sample = normalize(sample) * .random(in: 0...1)

    let t = Float(i) / 64
    let scale = 0.1 + 0.9 * t * t        // cluster near the center
    return SIMD4<Float>(sample * scale, 0)
}

std::mt19937 rng(7);
auto random = [&](float lo, float hi) { return std::uniform_real_distribution<float>(lo, hi)(rng); };

std::vector<simd::float4> kernel;
for (int i = 0; i < 64; i++) {
    simd::float3 sample = {random(-1, 1), random(-1, 1), random(0, 1)};
    sample = simd::normalize(sample) * random(0, 1);

    float t = float(i) / 64.0f;
    float scale = 0.1f + 0.9f * t * t;        // cluster near the center
    kernel.push_back(simd_make_float4(sample * scale, 0));
}

Salva il kernel in un buffer per lo shader.

Rotazione casuale#

64 campioni per pixel sono già tanti, e non bastano ancora a evitare bande visibili.
Ruotare il kernel in modo diverso in ogni pixel trasforma le bande in un rumore fine, che una sfocatura poi elimina.
Una minuscola texture 4 × 4 di vettori casuali, ripetuta su tutto lo schermo, fornisce le rotazioni:

let noise: [SIMD4<Float>] = (0..<16).map { _ in
    SIMD4<Float>(.random(in: -1...1), .random(in: -1...1), 0, 0)
}

let descriptor = MTLTextureDescriptor.texture2DDescriptor(
    pixelFormat: .rgba32Float, width: 4, height: 4, mipmapped: false)
noiseTexture = device.makeTexture(descriptor: descriptor)!
noiseTexture.replace(region: MTLRegionMake2D(0, 0, 4, 4), mipmapLevel: 0,
                     withBytes: noise, bytesPerRow: 4 * MemoryLayout<SIMD4<Float>>.stride)

std::vector<simd::float4> noise;
for (int i = 0; i < 16; i++) {
    noise.push_back(simd::float4{random(-1, 1), random(-1, 1), 0, 0});
}

MTL::TextureDescriptor* descriptor = MTL::TextureDescriptor::texture2DDescriptor(
    MTL::PixelFormatRGBA32Float, 4, 4, false);
noiseTexture = device->newTexture(descriptor);
noiseTexture->replaceRegion(MTL::Region::Make2D(0, 0, 4, 4), 0,
                            noise.data(), 4 * sizeof(simd::float4));

Lo shader dell'SSAO#

L'uscita è una texture a un solo canale (.r8Unorm) che contiene il fattore di occlusione.

struct SSAOUniforms {
    float4x4 projection;
    float radius;
    float bias;
};

fragment float fragment_ssao(ScreenOut in [[stage_in]],
                             constant SSAOUniforms &uniforms [[buffer(0)]],
                             constant float4 *kernel [[buffer(1)]],
                             texture2d<float> positionTexture [[texture(0)]],
                             texture2d<float> normalTexture   [[texture(1)]],
                             texture2d<float> noiseTexture    [[texture(2)]]) {
    constexpr sampler clampSampler(filter::nearest, address::clamp_to_edge);

    uint2 pixel = uint2(in.position.xy);
    float3 position = positionTexture.read(pixel).xyz;       // view space
    float3 normal = normalize(normalTexture.read(pixel).xyz);
    float3 random = noiseTexture.read(pixel % 4).xyz;

    // A TBN basis that orients the hemisphere along the normal, rotated randomly.
    float3 tangent = normalize(random - normal * dot(random, normal));
    float3 bitangent = cross(normal, tangent);
    float3x3 TBN = float3x3(tangent, bitangent, normal);

    float occlusion = 0.0;
    for (int i = 0; i < 64; i++) {
        float3 samplePosition = position + TBN * kernel[i].xyz * uniforms.radius;

        // Project the sample to find its pixel.
        float4 clip = uniforms.projection * float4(samplePosition, 1.0);
        float2 uv = (clip.xy / clip.w) * float2(0.5, -0.5) + 0.5;

        float sceneZ = positionTexture.sample(clampSampler, uv).z;

        // Ignore occluders far outside the sampling radius.
        float rangeCheck = smoothstep(0.0, 1.0, uniforms.radius / abs(position.z - sceneZ));
        occlusion += (sceneZ >= samplePosition.z + uniforms.bias ? 1.0 : 0.0) * rangeCheck;
    }
    return 1.0 - occlusion / 64.0;
}

Punti da notare:

  • Nel nostro spazio vista destrorso la camera guarda lungo -z, quindi una z più grande è più vicina alla camera.
    Un campione è occluso quando la superficie della scena in quel pixel è più vicina del campione.
  • Il bias, intorno a 0.025, impedisce a una superficie piatta di occludere sé stessa.
  • Il controllo sul raggio impedisce a un oggetto lontano sullo sfondo di scurire il bordo di qualcosa che gli sta davanti.
  • Leggere pixel % 4 ripete la texture di rumore su tutto lo schermo senza un sampler.
  • La proiezione verso le coordinate di texture ribalta y, come per le shadow map.

Un raggio di circa 0.5 unità di mondo è un buon punto di partenza.

Sfocatura#

Il risultato grezzo ha un motivo di rumore 4 × 4 ben visibile.
Una sfocatura a scatola della stessa dimensione lo elimina esattamente:

fragment float fragment_ssaoBlur(ScreenOut in [[stage_in]],
                                 texture2d<float> ssao [[texture(0)]]) {
    int2 pixel = int2(in.position.xy);
    int2 size = int2(ssao.get_width(), ssao.get_height());
    float result = 0.0;
    for (int x = -2; x < 2; x++) {
        for (int y = -2; y < 2; y++) {
            int2 p = clamp(pixel + int2(x, y), int2(0), size - 1);
            result += ssao.read(uint2(p)).r;
        }
    }
    return result / 16.0;
}

Applicarla#

L'ambient occlusion riguarda solo la luce ambient.
Nel lighting pass del deferred:

float ao = ssaoTexture.read(pixel).r;
float3 ambient = albedo * 0.3 * ao;

Moltiplicare per l'occlusione l'intero risultato illuminato è un errore comune.
Scurisce le superfici illuminate direttamente, e l'effetto è sporco.

Regolazione e costo#

  • Calcola l'SSAO a metà risoluzione.
    È informazione a bassa frequenza, e la sfocatura nasconde la differenza.
  • Con una buona sfocatura bastano spesso da 16 a 32 campioni.
  • Elevare il risultato a potenza (pow(ao, 2.0)) aumenta il contrasto.

L'SSAO conosce solo le superfici visibili, quindi l'occlusione può comparire o sparire quando gli oggetti entrano ed escono dallo schermo.
Varianti come HBAO e GTAO migliorano l'accuratezza, e il ray tracing calcola la vera ambient occlusion sull'hardware che lo supporta.

Esercizi#

  • Manda a schermo l'occlusione grezza e quella sfocata.
    Mostra la soluzione

    Dal pass di composizione restituisci l'occlusione come colore grigio, una volta dalla texture grezza e una da quella sfocata.
    La demo interattiva le ha entrambe: scegli "Occlusion buffer" e accendi o spegni la sfocatura.

  • Varia il raggio e il numero di campioni e trova l'impostazione più economica che renda ancora bene.
    Mostra la soluzione

    Un raggio vicino a 0.5 unità di mondo scurisce gli angoli senza creare aloni sulle superfici aperte; raggi più grandi danno un aspetto sporco.
    Sedici campioni con la sfocatura rendono quasi come sessantaquattro senza, a un quarto del costo.
    Calcolare l'occlusione a metà risoluzione dimezza ancora il costo.
