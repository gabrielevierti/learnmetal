Trasformazioni#

Progetto di esempio examples/Sources/05-Transformations, si esegue con swift run Transformations. Scarica tutti gli esempi oppure guarda come eseguirli.

Finora gli oggetti stanno dove li mettono i loro vertici.
Per muoverli, ruotarli e scalarli senza riscrivere i vertex buffer a ogni frame, moltiplichiamo ogni vertice per una matrice.
Questo capitolo è un giro rapido nella matematica, seguito da un piccolo file di supporto in Swift che useremo per il resto della serie.

Vettori#

Un vettore è una direzione con una lunghezza.
In grafica usiamo i vettori anche per le posizioni (una direzione a partire dall'origine) e per i colori.
Le operazioni che contano:

  • Somma e sottrazione lavorano componente per componente.
    b - a è il vettore che punta da a a b.
  • Lunghezza: length(v) è la radice quadrata di x² + y² + z².
    Un vettore di lunghezza 1 è un vettore unitario, e normalize(v) porta qualsiasi vettore a lunghezza 1.
  • Prodotto scalare: dot(a, b) = a.x*b.x + a.y*b.y + a.z*b.z.
    Per vettori unitari è uguale al coseno dell'angolo tra i due: 1 se sono paralleli, 0 se perpendicolari, -1 se opposti.
    Tutta l'illuminazione si costruisce su questo.
  • Prodotto vettoriale: cross(a, b) è un vettore perpendicolare a entrambi.

Il modulo simd di Swift li fornisce tutti, con gli stessi nomi di MSL.

Matrici#

Una matrice 4×4 può esprimere qualsiasi combinazione di scala, rotazione e traslazione.
Moltiplicare una matrice per un vettore applica la trasformazione.

La scala mette i fattori sulla diagonale.
La traslazione mette lo spostamento nell'ultima colonna, ed è per questo che servono quattro dimensioni: una matrice 3×3 non può spostare un punto.
La quarta componente di un vettore, w, accende e spegne la traslazione.
Le posizioni usano w = 1 e vengono spostate; le direzioni usano w = 0 e no.

La rotazione di un angolo intorno a un asse riempie il blocco 3×3 in alto a sinistra di seni e coseni.
È raro scriverla a mano.

L'ordine conta#

Il prodotto tra matrici non è commutativo.
Con i vettori colonna, che è la convenzione sia di Metal sia di simd, la matrice più vicina al vettore si applica per prima:

let transform = translation * rotation * scale
// applied to a vertex: scale first, then rotate, then translate

simd::float4x4 transform = translation * rotation * scale;
// applied to a vertex: scale first, then rotate, then translate

Scala, poi ruota, poi trasla: è l'ordine che vuoi quasi sempre.
Traslare prima e ruotare dopo fa girare l'oggetto intorno all'origine come un sasso legato a una corda.

Un file di supporto per le matrici#

simd ci dà i tipi ma pochi costruttori.
Aggiungi Math.swift:

import simd

typealias Float3 = SIMD3<Float>

extension Float {
    var radians: Float { self * .pi / 180 }
}

extension float4x4 {
    static let identity = matrix_identity_float4x4

    init(translation t: Float3) {
        self = .identity
        columns.3 = SIMD4<Float>(t, 1)
    }

    init(scale s: Float3) {
        self.init(diagonal: SIMD4<Float>(s, 1))
    }

    init(rotation angle: Float, axis: Float3) {
        self.init(simd_quatf(angle: angle, axis: normalize(axis)))
    }

    /// The upper-left 3x3 part: rotation and scale without translation.
    var upperLeft: float3x3 {
        float3x3(SIMD3(columns.0.x, columns.0.y, columns.0.z),
                 SIMD3(columns.1.x, columns.1.y, columns.1.z),
                 SIMD3(columns.2.x, columns.2.y, columns.2.z))
    }
}

// Math.hpp
#pragma once
#include <simd/simd.h>
#include <cmath>

inline float radians(float degrees) { return degrees * float(M_PI) / 180.0f; }

inline simd::float4x4 translation(simd::float3 t) {
    simd::float4x4 m = matrix_identity_float4x4;
    m.columns[3] = simd_make_float4(t, 1.0f);
    return m;
}

inline simd::float4x4 scaling(simd::float3 s) {
    return simd_diagonal_matrix(simd_make_float4(s, 1.0f));
}

inline simd::float4x4 rotation(float angle, simd::float3 axis) {
    return simd_matrix4x4(simd_quaternion(angle, simd::normalize(axis)));
}

/// The upper-left 3x3 part: rotation and scale without translation.
inline simd::float3x3 upperLeft(const simd::float4x4& m) {
    return simd_matrix(m.columns[0].xyz, m.columns[1].xyz, m.columns[2].xyz);
}

Gli angoli sono ovunque in radianti; 45.radians converte dai gradi.
Le matrici sono memorizzate in ordine column-major: columns.3 è la quarta colonna, dove vive la traslazione.
Il float4x4 di MSL usa lo stesso layout, quindi una matrice Swift si può copiare tale e quale in un buffer di uniform.

La rotazione è costruita a partire da un quaternione, una rappresentazione della rotazione con quattro numeri che non soffre del gimbal lock, il problema delle rotazioni concatenate attorno agli assi.
Per usarlo non serve conoscerne la teoria.

Trasformare il rettangolo#

Aggiungi una matrice agli uniform e moltiplica nella vertex function:

struct Uniforms {
    float4x4 transform;
};

vertex VertexOut vertex_main(VertexIn in [[stage_in]],
                             constant Uniforms &uniforms [[buffer(1)]]) {
    VertexOut out;
    out.position = uniforms.transform * float4(in.position, 1.0);
    out.uv = in.uv;
    return out;
}

Gli uniform usano lo slot 1 dei buffer di vertice perché lo slot 0 contiene i dati dei vertici.
Da qui in avanti è la nostra convenzione: slot 0 per i vertici, slot 1 per gli uniform.

struct Uniforms {
    var transform: float4x4
}

// in draw(in:)
let time = Float(CACurrentMediaTime() - startTime)
var uniforms = Uniforms(
    transform: float4x4(translation: [0.5, -0.5, 0])
             * float4x4(rotation: time, axis: [0, 0, 1])
             * float4x4(scale: [0.5, 0.5, 0.5]))
encoder.setVertexBytes(&uniforms, length: MemoryLayout<Uniforms>.stride, index: 1)

struct Uniforms {
    simd::float4x4 transform;
};

// in draw()
float time = float(glfwGetTime());
Uniforms uniforms{
    translation(simd::float3{0.5f, -0.5f, 0.0f})
        * rotation(time, simd::float3{0, 0, 1})
        * scaling(simd::float3{0.5f, 0.5f, 0.5f})
};
encoder->setVertexBytes(&uniforms, sizeof(Uniforms), 1);

Ora il rettangolo è grande la metà, sta nell'angolo in basso a destra e gira intorno al proprio centro.
Se la finestra non è quadrata, mentre ruota appare deformato.
È previsto, e la matrice di proiezione del prossimo capitolo lo sistema.

Esercizi#

  • Scambia la traslazione con la rotazione e prova a prevedere il risultato prima di eseguire.
    Mostra la soluzione

    Con rotation * translation * scale il rettangolo viene scalato, poi allontanato dall'origine, poi ruotato.
    Adesso la rotazione agisce sul rettangolo già spostato, che quindi gira in cerchio intorno al centro dello schermo invece di ruotare sul posto.
    Provalo nella demo interattiva con il selettore dell'ordine.

  • Disegna il rettangolo una seconda volta nell'angolo in alto a sinistra, con una scala che segue sin(time).
    Ti servono solo un secondo setVertexBytes e una seconda draw call.
    Mostra la soluzione

    Costruisci una seconda matrice, inviala con un secondo setVertexBytes e ripeti la draw call.
    Il vertex buffer, la pipeline e la texture restano collegati.
    In Swift: float4x4(translation: [-0.5, 0.5, 0]) * float4x4(scale: Float3(repeating: abs(sin(time)) * 0.5)).
    La scala passa per lo zero, dove il rettangolo sparisce per un frame.
