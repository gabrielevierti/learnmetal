Camera#

Progetto di esempio examples/Sources/07-Camera, si esegue con swift run Camera. Scarica tutti gli esempi oppure guarda come eseguirli.

Una matrice view fissa mostra la scena da un punto solo.
Una camera con cui volare dentro la scena è una matrice view ricostruita a ogni frame a partire da una posizione e da una direzione, entrambe guidate dall'input.

La matrice look-at#

Una camera è definita da dove si trova, da che cosa guarda e da qual è il suo alto.
Da questi tre dati ricaviamo tre assi perpendicolari e costruiamo una matrice che porta il mondo nel sistema di riferimento della camera.
Aggiungi a Math.swift:

extension float4x4 {
    /// Right-handed view matrix.
    init(lookAt eye: Float3, center: Float3, up: Float3) {
        let z = normalize(eye - center)        // points backward, away from the target
        let x = normalize(cross(up, z))        // right
        let y = cross(z, x)                    // true up
        self.init(columns: (
            SIMD4<Float>(x.x, y.x, z.x, 0),
            SIMD4<Float>(x.y, y.y, z.y, 0),
            SIMD4<Float>(x.z, y.z, z.z, 0),
            SIMD4<Float>(-dot(x, eye), -dot(y, eye), -dot(z, eye), 1)))
    }
}

/// Right-handed view matrix.
inline simd::float4x4 lookAt(simd::float3 eye, simd::float3 center, simd::float3 up) {
    simd::float3 z = simd::normalize(eye - center);        // points backward, away from the target
    simd::float3 x = simd::normalize(simd::cross(up, z));  // right
    simd::float3 y = simd::cross(z, x);                    // true up
    return simd_matrix(simd_make_float4(x.x, y.x, z.x, 0),
                       simd_make_float4(x.y, y.y, z.y, 0),
                       simd_make_float4(x.z, y.z, z.z, 0),
                       simd_make_float4(-simd::dot(x, eye), -simd::dot(y, eye), -simd::dot(z, eye), 1));
}

La parte di rotazione allinea il mondo agli assi della camera, e l'ultima colonna porta la camera nell'origine.
Provala facendo orbitare la camera intorno alla scena:

let radius: Float = 10
let eye = Float3(sin(time) * radius, 0, cos(time) * radius)
uniforms.view = float4x4(lookAt: eye, center: [0, 0, 0], up: [0, 1, 0])

float radius = 10.0f;
simd::float3 eye = {std::sin(time) * radius, 0, std::cos(time) * radius};
uniforms.view = lookAt(eye, simd::float3{0, 0, 0}, simd::float3{0, 1, 0});

Una camera libera#

Per muoversi liberamente conserva una posizione e due angoli.
Lo yaw gira a sinistra e a destra, il pitch guarda in alto e in basso.

import simd

final class Camera {
    var position = Float3(0, 0, 3)
    var yaw: Float = -90      // degrees; -90 looks down -z
    var pitch: Float = 0
    var fov: Float = 45

    var speed: Float = 2.5
    var sensitivity: Float = 0.1

    var front: Float3 {
        let y = yaw.radians, p = pitch.radians
        return normalize(Float3(cos(y) * cos(p), sin(p), sin(y) * cos(p)))
    }
    var right: Float3 { normalize(cross(front, [0, 1, 0])) }

    var viewMatrix: float4x4 {
        float4x4(lookAt: position, center: position + front, up: [0, 1, 0])
    }

    func move(forward: Float, strafe: Float, deltaTime: Float) {
        position += front * forward * speed * deltaTime
        position += right * strafe * speed * deltaTime
    }

    func rotate(deltaX: Float, deltaY: Float) {
        yaw += deltaX * sensitivity
        pitch += deltaY * sensitivity
        pitch = min(max(pitch, -89), 89)
    }

    func zoom(_ amount: Float) {
        fov = min(max(fov - amount, 1), 60)
    }
}

#include <algorithm>
#include "Math.hpp"

class Camera {
public:
    simd::float3 position = {0, 0, 3};
    float yaw = -90;      // degrees; -90 looks down -z
    float pitch = 0;
    float fov = 45;

    float speed = 2.5f;
    float sensitivity = 0.1f;

    simd::float3 front() const {
        float y = radians(yaw), p = radians(pitch);
        return simd::normalize(simd::float3{std::cos(y) * std::cos(p), std::sin(p), std::sin(y) * std::cos(p)});
    }
    simd::float3 right() const { return simd::normalize(simd::cross(front(), simd::float3{0, 1, 0})); }

    simd::float4x4 viewMatrix() const {
        return lookAt(position, position + front(), simd::float3{0, 1, 0});
    }

    void move(float forward, float strafe, float deltaTime) {
        position += front() * forward * speed * deltaTime;
        position += right() * strafe * speed * deltaTime;
    }

    void rotate(float deltaX, float deltaY) {
        yaw += deltaX * sensitivity;
        pitch = std::clamp(pitch + deltaY * sensitivity, -89.0f, 89.0f);
    }

    void zoom(float amount) {
        fov = std::clamp(fov - amount, 1.0f, 60.0f);
    }
};

front trasforma i due angoli in una direzione con un po' di trigonometria.
Il pitch è limitato poco prima dei 90 gradi perché guardando dritto in alto front diventa parallelo al vettore up, e il prodotto vettoriale dentro lookAt si annulla.

Delta time#

I frame non durano tutti lo stesso tempo.
Il movimento va moltiplicato per il tempo trascorso dall'ultimo frame, il delta time, altrimenti la velocità della camera dipenderebbe dal frame rate:

var lastFrameTime = CACurrentMediaTime()

// in draw(in:)
let now = CACurrentMediaTime()
let deltaTime = Float(now - lastFrameTime)
lastFrameTime = now

double lastFrameTime = glfwGetTime();

// in draw()
double now = glfwGetTime();
float deltaTime = float(now - lastFrameTime);
lastFrameTime = now;

Input#

AppKit e UIKit consegnano l'input sotto forma di eventi, cosa scomoda per un game loop che vuole chiedere "W è premuto in questo momento?".
Il framework GameController permette di interrogare tastiera e mouse sia su macOS sia su iPadOS:

import GameController

func updateCamera(deltaTime: Float) {
    var forward: Float = 0
    var strafe: Float = 0
    if let keyboard = GCKeyboard.coalesced?.keyboardInput {
        if keyboard.button(forKeyCode: .keyW)?.isPressed == true { forward += 1 }
        if keyboard.button(forKeyCode: .keyS)?.isPressed == true { forward -= 1 }
        if keyboard.button(forKeyCode: .keyD)?.isPressed == true { strafe += 1 }
        if keyboard.button(forKeyCode: .keyA)?.isPressed == true { strafe -= 1 }
    }
    camera.move(forward: forward, strafe: strafe, deltaTime: deltaTime)
}

// GLFW lets you poll the keyboard directly.
void updateCamera(GLFWwindow* window, Camera& camera, float deltaTime) {
    float forward = 0, strafe = 0;
    if (glfwGetKey(window, GLFW_KEY_W) == GLFW_PRESS) forward += 1;
    if (glfwGetKey(window, GLFW_KEY_S) == GLFW_PRESS) forward -= 1;
    if (glfwGetKey(window, GLFW_KEY_D) == GLFW_PRESS) strafe += 1;
    if (glfwGetKey(window, GLFW_KEY_A) == GLFW_PRESS) strafe -= 1;
    camera.move(forward, strafe, deltaTime);
}

Il movimento del mouse arriva attraverso un handler che riporta gli spostamenti.
Registralo una volta sola, per esempio nell'init del renderer:

NotificationCenter.default.addObserver(forName: .GCMouseDidConnect, object: nil, queue: .main) { [weak self] note in
    guard let mouse = note.object as? GCMouse else { return }
    mouse.mouseInput?.mouseMovedHandler = { _, deltaX, deltaY in
        self?.camera.rotate(deltaX: deltaX, deltaY: deltaY)
    }
    mouse.mouseInput?.scroll.valueChangedHandler = { _, _, y in
        self?.camera.zoom(y)
    }
}

// Mouse movement and scrolling arrive through callbacks. Register them once after creating the window.
glfwSetInputMode(window, GLFW_CURSOR, GLFW_CURSOR_DISABLED);    // capture the cursor
glfwSetWindowUserPointer(window, &camera);

glfwSetCursorPosCallback(window, [](GLFWwindow* w, double x, double y) {
    static double lastX = x, lastY = y;
    auto* camera = static_cast<Camera*>(glfwGetWindowUserPointer(w));
    camera->rotate(float(x - lastX), float(lastY - y));         // window y grows downward
    lastX = x;
    lastY = y;
});
glfwSetScrollCallback(window, [](GLFWwindow* w, double, double yOffset) {
    static_cast<Camera*>(glfwGetWindowUserPointer(w))->zoom(float(yOffset));
});

deltaY è positivo quando il mouse sale, quindi il pitch aumenta e la camera guarda in alto.
Su macOS la finestra deve essere quella attiva perché l'interrogazione della tastiera funzioni; cliccala una volta dopo l'avvio.
Lo stesso framework legge i controller di gioco attraverso GCController, che su iPhone è la scelta naturale.

L'input in C++

La versione C++ usa GLFW, da cui arriva già la finestra, al posto del framework GameController.
glfwGetKey interroga la tastiera, e le callback del cursore e dello scroll consegnano il movimento del mouse.
GLFW riporta la posizione del cursore con y che cresce verso il basso, quindi la callback sottrae nell'ordine inverso per far aumentare il pitch quando il mouse sale.

Esercizi#

  • Trasforma la camera libera in una camera in prima persona che non può lasciare il piano del terreno (tieni fisso position.y).
    Mostra la soluzione

    Muoviti lungo un vettore front appiattito, così guardare in alto o in basso non cambia la tua altezza: normalizza (front.x, 0, front.z) e usa quello in move.
    Lascia invariata viewMatrix, così puoi ancora guardarti intorno liberamente.

  • Aggiungi Q ed E per salire e scendere in verticale.
    Mostra la soluzione

    Aggiungi a move un input verticale e applicalo lungo l'asse up del mondo: position.y += vertical * speed * deltaTime.
    Leggi i due tasti come fai con W e S (.keyQ e .keyE con GameController, GLFW_KEY_Q e GLFW_KEY_E con GLFW).

  • Tieni premuto Shift per triplicare la velocità di movimento.
    Mostra la soluzione

    Moltiplica la velocità finché Shift è premuto.
    Con GameController controlla keyboard.button(forKeyCode: .leftShift)?.isPressed; con GLFW controlla glfwGetKey(window, GLFW_KEY_LEFT_SHIFT) == GLFW_PRESS.
    Poi passa deltaTime * 3 a move, oppure scala speed per quel frame.
