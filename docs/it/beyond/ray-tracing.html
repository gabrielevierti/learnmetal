Ray tracing#

La rasterizzazione risponde molto in fretta a una domanda: quale triangolo copre questo pixel?
Tutto il resto, comprese ombre, riflessi e ambient occlusion, è stato finora un'approssimazione costruita sopra: shadow map, environment map, trucchi in screen space.
Ognuna da qualche parte cede.

Il ray tracing risponde a una domanda più generale: che cosa colpisce per primo un raggio che parte da qui e va da quella parte?
Con questa sola operazione ombre, riflessi e occlusione diventano esatti e quasi banali da esprimere.
Metal ha un'API di ray tracing che gira su tutto Apple silicon, con accelerazione hardware sui chip recenti.

Questo capitolo è un'introduzione.
Lo scopo è capire i pezzi e tracciare i tuoi primi raggi, poi aggiungere ombre in ray tracing al renderer rasterizzato che hai già.

Acceleration structure#

Confrontare un raggio con ogni triangolo di una scena è senza speranza.
Una acceleration structure organizza i triangoli in un albero di bounding box, così un raggio può saltarne quasi tutti.
Metal costruisce e attraversa questa struttura per te.

I livelli sono due:

  • Una primitive acceleration structure contiene i triangoli di una mesh.
  • Una instance acceleration structure contiene molte istanze di strutture primitive, ognuna con la sua trasformazione.
    Muovere un oggetto significa aggiornare una matrice e riadattare il livello superiore, non ricostruire la mesh.

Prima controlla il supporto:

guard device.supportsRaytracing else { /* fall back to shadow maps */ return }

if (!device->supportsRaytracing()) { /* fall back to shadow maps */ return; }

Costruire una struttura primitiva#

Descrivi la geometria usando i vertex buffer e gli index buffer che hai già:

let geometry = MTLAccelerationStructureTriangleGeometryDescriptor()
geometry.vertexBuffer = mesh.vertexBuffers[0].buffer
geometry.vertexBufferOffset = mesh.vertexBuffers[0].offset
geometry.vertexStride = 32                       // positions are at offset 0
geometry.indexBuffer = submesh.indexBuffer.buffer
geometry.indexBufferOffset = submesh.indexBuffer.offset
geometry.indexType = submesh.indexType
geometry.triangleCount = submesh.indexCount / 3

let descriptor = MTLPrimitiveAccelerationStructureDescriptor()
descriptor.geometryDescriptors = [geometry]

MTL::AccelerationStructureTriangleGeometryDescriptor* geometry =
    MTL::AccelerationStructureTriangleGeometryDescriptor::alloc()->init();
geometry->setVertexBuffer(mesh.vertexBuffer);
geometry->setVertexBufferOffset(0);
geometry->setVertexStride(sizeof(MeshVertex));        // positions are at offset 0
geometry->setIndexBuffer(submesh.indexBuffer);
geometry->setIndexBufferOffset(0);
geometry->setIndexType(MTL::IndexTypeUInt32);
geometry->setTriangleCount(submesh.indexCount / 3);

MTL::PrimitiveAccelerationStructureDescriptor* descriptor =
    MTL::PrimitiveAccelerationStructureDescriptor::alloc()->init();
descriptor->setGeometryDescriptors(NS::Array::array(geometry));

La costruzione avviene sulla GPU, attraverso un encoder dedicato:

let sizes = device.accelerationStructureSizes(descriptor: descriptor)
let accelerationStructure = device.makeAccelerationStructure(size: sizes.accelerationStructureSize)!
let scratch = device.makeBuffer(length: sizes.buildScratchBufferSize, options: .storageModePrivate)!

let commandBuffer = commandQueue.makeCommandBuffer()!
let encoder = commandBuffer.makeAccelerationStructureCommandEncoder()!
encoder.build(accelerationStructure: accelerationStructure,
              descriptor: descriptor,
              scratchBuffer: scratch,
              scratchBufferOffset: 0)
encoder.endEncoding()
commandBuffer.commit()

MTL::AccelerationStructureSizes sizes = device->accelerationStructureSizes(descriptor);
MTL::AccelerationStructure* accelerationStructure =
    device->newAccelerationStructure(sizes.accelerationStructureSize);
MTL::Buffer* scratch = device->newBuffer(sizes.buildScratchBufferSize, MTL::ResourceStorageModePrivate);

MTL::CommandBuffer* commandBuffer = commandQueue->commandBuffer();
MTL::AccelerationStructureCommandEncoder* encoder = commandBuffer->accelerationStructureCommandEncoder();
encoder->buildAccelerationStructure(accelerationStructure, descriptor, scratch, 0);
encoder->endEncoding();
commandBuffer->commit();

Costruisci la geometria statica una volta sola, al caricamento.
Lo stesso encoder può compattare una struttura per risparmiare memoria e riadattarla dopo che i vertici si sono mossi.

Intersecare i raggi in uno shader#

In Metal il ray tracing non è una pipeline separata.
Qualsiasi shader, che sia un kernel o una fragment function, può ricevere una acceleration structure e lanciarvi dei raggi.

#include <metal_stdlib>
using namespace metal;
using namespace raytracing;

kernel void trace(texture2d<float, access::write> output [[texture(0)]],
                  constant CameraUniforms &camera [[buffer(0)]],
                  primitive_acceleration_structure scene [[buffer(1)]],
                  uint2 gid [[thread_position_in_grid]]) {
    // A ray through this pixel.
    float2 size = float2(output.get_width(), output.get_height());
    float2 ndc = (float2(gid) + 0.5) / size * 2.0 - 1.0;
    ndc.y = -ndc.y;

    ray r;
    r.origin = camera.position;
    r.direction = normalize(camera.forward
                          + ndc.x * camera.right * camera.tanHalfFov * camera.aspect
                          + ndc.y * camera.up * camera.tanHalfFov);
    r.min_distance = 0.001;
    r.max_distance = INFINITY;

    intersector<triangle_data> i;
    intersection_result<triangle_data> hit = i.intersect(r, scene);

    float3 color = float3(0.1, 0.1, 0.15);                 // background
    if (hit.type == intersection_type::triangle) {
        // Visualize the barycentric coordinates of the hit.
        float2 b = hit.triangle_barycentric_coord;
        color = float3(1.0 - b.x - b.y, b.x, b.y);
    }
    output.write(float4(color, 1.0), gid);
}

computeEncoder.setAccelerationStructure(accelerationStructure, bufferIndex: 1)

computeEncoder->setAccelerationStructure(accelerationStructure, 1);

Il risultato dell'intersezione ti dice la distanza dal punto colpito, quale primitiva e quale geometria sono state colpite e le coordinate baricentriche del punto dentro il triangolo.
Con l'indice della primitiva cerchi i vertici del triangolo nei tuoi buffer e interpoli normali e coordinate di texture.
Metal può anche conservare dentro la struttura piccoli dati per primitiva, per rendere più economica questa ricerca.

Esegui questo kernel, mostra la texture di uscita con il triangolo a tutto schermo, e hai un'immagine in ray tracing della tua mesh senza alcuna rasterizzazione.

Rendering ibrido: ombre in ray tracing#

Un path tracer completo è un progetto a sé.
L'uso più pratico del ray tracing è quello ibrido: rasterizza la scena come prima e usa i raggi solo per gli effetti che la rasterizzazione fa male.

Le ombre sono il guadagno più facile.
Nella fragment function di illuminazione lancia un raggio dalla superficie verso la luce.
Se colpisce qualcosa, il punto è in ombra:

static float traceShadow(float3 worldPosition, float3 normal, float3 lightPosition,
                         primitive_acceleration_structure scene) {
    float3 toLight = lightPosition - worldPosition;
    float distance = length(toLight);

    ray r;
    r.origin = worldPosition + normal * 0.001;     // step off the surface
    r.direction = toLight / distance;
    r.min_distance = 0.001;
    r.max_distance = distance;

    intersector<triangle_data> i;
    i.accept_any_intersection(true);               // any hit will do
    return i.intersect(r, scene).type == intersection_type::none ? 1.0 : 0.0;
}

fragment float4 fragment_main(VertexOut in [[stage_in]],
                              constant FragmentUniforms &uniforms [[buffer(1)]],
                              primitive_acceleration_structure scene [[buffer(3)]]) {
    ...
    float lit = traceShadow(in.worldPosition, normalize(in.normal), light.position, scene);
    color += lit * (diffuse + specular);
}

encoder.setFragmentAccelerationStructure(accelerationStructure, bufferIndex: 3)

encoder->setFragmentAccelerationStructure(accelerationStructure, 3);

Confronta con Shadow mapping e Ombre da luci puntiformi: nessun pass in più, nessuna texture di ombre, nessun bias da regolare, nessun limite di risoluzione, e funziona con qualsiasi tipo di luce.
accept_any_intersection(true) permette all'attraversamento di fermarsi al primo punto colpito, e questo rende economici i raggi d'ombra.

Lo stesso schema dà:

  • Riflessi: traccia lungo reflect(-V, N) e calcola il colore del punto colpito.
  • Ambient occlusion: traccia alcuni raggi corti nell'emisfero sopra la superficie e conta quelli che colpiscono qualcosa.
    È occlusione vera, e sostituisce l'SSAO.
  • Ombre morbide: punta i raggi verso punti casuali di una luce ad area e fai la media su più frame.

Rumore e denoising#

Un raggio per pixel dà ombre nette e riflessi a specchio.
Gli effetti morbidi richiedono molti raggi in direzioni casuali, e un budget in tempo reale ne permette solo pochi per pixel.
Il risultato è rumoroso.
Il rimedio consueto è accumulare i risultati su più frame e fare denoising.
Metal Performance Shaders include MPSSVGFDenoiser, e sui sistemi recenti MetalFX offre un upscaling con denoising.

Per andare oltre#

  • Le instance acceleration structure per le scene con molti oggetti in movimento (MTLInstanceAccelerationStructureDescriptor).
  • Le intersection function per primitive personalizzate come sfere e curve, e per la geometria con alpha test come il fogliame.
  • Il path tracing: seguire i raggi per più rimbalzi e calcolare l'illuminazione globale.
    Il codice di esempio di Apple "Accelerating ray tracing using Metal" è un path tracer compatto e leggibile, ed è il passo successivo naturale.
