Metal avanzato

Instancing#

Progetto di esempio examples/Sources/13-Instancing, si esegue con swift run Instancing. Scarica tutti gli esempi oppure guarda come eseguirli.

Un prato, una foresta, una fascia di asteroidi: migliaia di copie della stessa mesh, ognuna con una trasformazione diversa.
Fare una draw call per copia spreca tempo di CPU, perché ogni chiamata ha un costo fisso per quanto piccola sia la mesh.
L'instancing disegna tutte le copie con una sola chiamata.

Draw call con istanze#

Ogni metodo di disegno ha una variante con un instanceCount:

encoder.drawPrimitives(type: .triangle,
                       vertexStart: 0,
                       vertexCount: 36,
                       instanceCount: 1000)

encoder.drawIndexedPrimitives(type: .triangle,
                              indexCount: submesh.indexCount,
                              indexType: submesh.indexType,
                              indexBuffer: submesh.indexBuffer.buffer,
                              indexBufferOffset: submesh.indexBuffer.offset,
                              instanceCount: 1000)

encoder->drawPrimitives(MTL::PrimitiveTypeTriangle,
                        NS::UInteger(0),          // vertex start
                        NS::UInteger(36),         // vertex count
                        NS::UInteger(1000));      // instance count

encoder->drawIndexedPrimitives(MTL::PrimitiveTypeTriangle,
                               submesh.indexCount,
                               MTL::IndexTypeUInt32,
                               submesh.indexBuffer,
                               0,                 // index buffer offset
                               1000);             // instance count

La GPU esegue la vertex function per ogni vertice di ogni istanza.
L'unica differenza tra le istanze è l'input predefinito [[instance_id]], che conta da 0.
Tutto ciò che fa apparire diverse le istanze si ricava da quel numero.

I dati delle istanze in un buffer#

Metti in un buffer una struct per istanza e indicizzala con l'ID dell'istanza:

struct InstanceData {
    float4x4 model;
    float4 color;
};

vertex VertexOut vertex_instanced(VertexIn in [[stage_in]],
                                  uint instanceID [[instance_id]],
                                  constant Uniforms &uniforms [[buffer(1)]],
                                  const device InstanceData *instances [[buffer(2)]]) {
    InstanceData instance = instances[instanceID];

    VertexOut out;
    float4 world = instance.model * float4(in.position, 1.0);
    out.position = uniforms.projection * uniforms.view * world;
    out.worldPosition = world.xyz;
    out.normal = (instance.model * float4(in.normal, 0.0)).xyz;
    out.uv = in.uv;
    out.color = instance.color;
    return out;
}

Usare la matrice model per la normale è corretto solo con rotazioni e scale uniformi.
Se ti serve una scala non uniforme, salva una matrice delle normali per ogni istanza.

struct InstanceData {
    var model: float4x4
    var color: SIMD4<Float>
}

let instanceBuffer = device.makeBuffer(length: MemoryLayout<InstanceData>.stride * instanceCount,
                                       options: .storageModeShared)!

let instances = instanceBuffer.contents().bindMemory(to: InstanceData.self, capacity: instanceCount)
for i in 0..<instanceCount {
    instances[i] = InstanceData(model: transforms[i], color: colors[i])
}

struct InstanceData {
    simd::float4x4 model;
    simd::float4 color;
};

MTL::Buffer* instanceBuffer = device->newBuffer(sizeof(InstanceData) * instanceCount,
                                                MTL::ResourceStorageModeShared);

InstanceData* instances = static_cast<InstanceData*>(instanceBuffer->contents());
for (int i = 0; i < instanceCount; i++) {
    instances[i] = InstanceData{transforms[i], colors[i]};
}

encoder.setVertexBuffer(instanceBuffer, offset: 0, index: 2)

encoder->setVertexBuffer(instanceBuffer, 0, 2);

Se vieni da OpenGL

Non servono attributi di vertice per istanza con i divisor, e non c'è limite alla dimensione dei dati per istanza.
Bastano un buffer e un indice.
Se preferisci comunque gli attributi, un layout del vertex descriptor può avanzare una volta per istanza: layouts[1].stepFunction = .perInstance.

Un campo di asteroidi#

Genera intorno a un pianeta un anello di rocce disposte, ruotate e scalate a caso:

func makeAsteroidTransforms(count: Int, radius: Float, spread: Float) -> [float4x4] {
    (0..<count).map { i in
        let angle = Float(i) / Float(count) * 2 * .pi
        let offset = { Float.random(in: -spread...spread) }
        let position = Float3(sin(angle) * radius + offset(),
                              offset() * 0.4,
                              cos(angle) * radius + offset())
        let scale = Float.random(in: 0.05...0.25)
        let rotation = Float.random(in: 0...(2 * .pi))

        return float4x4(translation: position)
             * float4x4(rotation: rotation, axis: [0.4, 0.6, 0.8])
             * float4x4(scale: Float3(repeating: scale))
    }
}

#include <random>

std::vector<simd::float4x4> makeAsteroidTransforms(int count, float radius, float spread) {
    std::mt19937 rng(42);
    auto random = [&](float lo, float hi) { return std::uniform_real_distribution<float>(lo, hi)(rng); };

    std::vector<simd::float4x4> transforms;
    for (int i = 0; i < count; i++) {
        float angle = float(i) / float(count) * 2.0f * float(M_PI);
        simd::float3 position = {std::sin(angle) * radius + random(-spread, spread),
                                 random(-spread, spread) * 0.4f,
                                 std::cos(angle) * radius + random(-spread, spread)};
        float scale = random(0.05f, 0.25f);

        transforms.push_back(translation(position)
                           * rotation(random(0, 2.0f * float(M_PI)), simd::float3{0.4f, 0.6f, 0.8f})
                           * scaling(simd::float3{scale, scale, scale}));
    }
    return transforms;
}

Disegnati con una chiamata per roccia, già poche migliaia di asteroidi costano a ogni frame un tempo di CPU apprezzabile.
Disegnati con l'instancing ne girano fluidi centomila, e il limite diventa quanti triangoli la GPU riesce a riempire.

Animare le istanze#

Dato che il buffer delle istanze è memoria condivisa, aggiornarlo è una semplice scrittura a ogni frame.
Usa lo schema con l'anello di buffer di Dati avanzati, così non sovrascrivi dati che la GPU sta ancora leggendo.
Per numeri molto grandi, spostare sulla GPU l'aggiornamento stesso con una compute function toglie del tutto la CPU dal ciclo.

Il culling e il passo successivo#

L'instancing disegna ogni istanza, visibile o no.
I mondi grandi fanno il culling sulla CPU e scrivono nel buffer solo le istanze visibili, oppure lo lasciano fare alla GPU: un compute pass confronta ogni istanza con il frustum della vista e scrive le sopravvissute in un indirect command buffer, un elenco di draw call codificato dalla GPU stessa (MTLIndirectCommandBuffer).
Quella tecnica, il rendering guidato dalla GPU, va oltre questa serie, ma l'instancing ne è il primo passo.

Esercizi#

  • Disegna una griglia di 100 × 100 cubi con una sola chiamata, colorando ciascuno in base al suo ID di istanza.
    Mostra la soluzione

    Calcola la posizione nella griglia dall'ID dell'istanza nella vertex function, senza alcun buffer di istanze.

    float column = float(instanceID % 100);
float row = float(instanceID / 100);
float3 offset = float3(column - 50.0, 0.0, row - 50.0) * 1.5;
out.position = uniforms.projection * uniforms.view * float4(in.position + offset, 1.0);
out.color = float3(column, row, 50.0) / 100.0;

    Disegna con un numero di istanze pari a 10.000.

  • Fai ruotare l'anello di asteroidi passando un uniform con il tempo e ruotando nella vertex function, senza aggiornare alcun buffer dalla CPU.
    Mostra la soluzione

    Ruota la posizione in spazio mondo dell'istanza intorno all'asse y di un angolo che dipende dal tempo.
    Il buffer delle istanze non viene mai riscritto.

    float angle = uniforms.time * 0.05;
float c = cos(angle), s = sin(angle);
float4 world = instance.model * float4(in.position, 1.0);
world.xz = float2(world.x * c + world.z * s, world.z * c - world.x * s);

    La demo interattiva fa questo: l'angolo dell'anello comprende uniforms.time.
