Metal avanzato

Test di stencil#

Accanto al depth buffer vive lo stencil buffer: 8 bit per pixel che puoi scrivere liberamente mentre disegni e controllare in seguito.
Permette di marcare delle zone dello schermo e poi di limitare il disegno a quelle.
Contorni, portali, specchi e maschere per l'interfaccia sono gli usi classici.

Attivare uno stencil buffer#

Di norma profondità e stencil condividono una sola texture con un formato combinato:

view.depthStencilPixelFormat = .depth32Float_stencil8
view.clearStencil = 0

pipelineDescriptor.depthAttachmentPixelFormat = .depth32Float_stencil8
pipelineDescriptor.stencilAttachmentPixelFormat = .depth32Float_stencil8

// The depth texture you create gets the combined format...
depthTextureDescriptor->setPixelFormat(MTL::PixelFormatDepth32Float_Stencil8);

// ...and is attached to the pass as both depth and stencil.
passDescriptor->depthAttachment()->setTexture(depthStencilTexture);
passDescriptor->stencilAttachment()->setTexture(depthStencilTexture);
passDescriptor->stencilAttachment()->setLoadAction(MTL::LoadActionClear);
passDescriptor->stencilAttachment()->setClearStencil(0);

pipelineDescriptor->setDepthAttachmentPixelFormat(MTL::PixelFormatDepth32Float_Stencil8);
pipelineDescriptor->setStencilAttachmentPixelFormat(MTL::PixelFormatDepth32Float_Stencil8);

Ogni pipeline state usato nel pass deve dichiarare entrambi i formati.

Il test di stencil#

Per ogni fragment la GPU confronta un valore di riferimento, che imposti sull'encoder, con il valore nel buffer.
Il confronto e la reazione sono descritti da un MTLStencilDescriptor dentro il depth-stencil descriptor:

Proprietà Significato
stencilCompareFunction Come si confrontano il riferimento e il valore salvato.
stencilFailureOperation Che cosa fare del valore salvato se il test di stencil fallisce.
depthFailureOperation Se il test di stencil passa ma quello di profondità fallisce.
depthStencilPassOperation Se passano entrambi.
readMask, writeMask Maschere di bit applicate nel confronto e nella scrittura.

Le operazioni sono .keep, .zero, .replace (salva il valore di riferimento), .incrementClamp, .decrementClamp, .invert, .incrementWrap e .decrementWrap.

Ci sono descriptor separati per i triangoli rivolti verso la camera e per quelli rivolti dall'altra parte, frontFaceStencil e backFaceStencil.

Contorni degli oggetti#

Un contorno di selezione si disegna in due passi:

  1. Disegna l'oggetto normalmente e scrivi 1 nello stencil buffer ovunque sia visibile.
  2. Disegna di nuovo l'oggetto, un po' ingrandito e con un colore piatto, solo dove lo stencil non vale 1.

La copia ingrandita viene scartata sopra l'oggetto stesso e sopravvive solo in un bordo sottile intorno.

State 1: scrivi 1 ovunque venga disegnato l'oggetto.

let writeStencil = MTLStencilDescriptor()
writeStencil.stencilCompareFunction = .always
writeStencil.depthStencilPassOperation = .replace

let writeDescriptor = MTLDepthStencilDescriptor()
writeDescriptor.depthCompareFunction = .less
writeDescriptor.isDepthWriteEnabled = true
writeDescriptor.frontFaceStencil = writeStencil
writeDescriptor.backFaceStencil = writeStencil
let writeState = device.makeDepthStencilState(descriptor: writeDescriptor)!

MTL::StencilDescriptor* writeStencil = MTL::StencilDescriptor::alloc()->init();
writeStencil->setStencilCompareFunction(MTL::CompareFunctionAlways);
writeStencil->setDepthStencilPassOperation(MTL::StencilOperationReplace);

MTL::DepthStencilDescriptor* writeDescriptor = MTL::DepthStencilDescriptor::alloc()->init();
writeDescriptor->setDepthCompareFunction(MTL::CompareFunctionLess);
writeDescriptor->setDepthWriteEnabled(true);
writeDescriptor->setFrontFaceStencil(writeStencil);
writeDescriptor->setBackFaceStencil(writeStencil);
MTL::DepthStencilState* writeState = device->newDepthStencilState(writeDescriptor);

State 2: disegna solo dove lo stencil non vale 1, ignorando la profondità.

let testStencil = MTLStencilDescriptor()
testStencil.stencilCompareFunction = .notEqual
testStencil.depthStencilPassOperation = .keep

let outlineDescriptor = MTLDepthStencilDescriptor()
outlineDescriptor.depthCompareFunction = .always
outlineDescriptor.isDepthWriteEnabled = false
outlineDescriptor.frontFaceStencil = testStencil
outlineDescriptor.backFaceStencil = testStencil
let outlineState = device.makeDepthStencilState(descriptor: outlineDescriptor)!

MTL::StencilDescriptor* testStencil = MTL::StencilDescriptor::alloc()->init();
testStencil->setStencilCompareFunction(MTL::CompareFunctionNotEqual);
testStencil->setDepthStencilPassOperation(MTL::StencilOperationKeep);

MTL::DepthStencilDescriptor* outlineDescriptor = MTL::DepthStencilDescriptor::alloc()->init();
outlineDescriptor->setDepthCompareFunction(MTL::CompareFunctionAlways);
outlineDescriptor->setDepthWriteEnabled(false);
outlineDescriptor->setFrontFaceStencil(testStencil);
outlineDescriptor->setBackFaceStencil(testStencil);
MTL::DepthStencilState* outlineState = device->newDepthStencilState(outlineDescriptor);

Il disegno:

// Floor and anything else that should not be outlined: the ordinary depth state.
encoder.setDepthStencilState(depthState)
drawFloor(encoder)

// 1. The cubes, marking the stencil buffer.
encoder.setDepthStencilState(writeState)
encoder.setStencilReferenceValue(1)
encoder.setRenderPipelineState(pipelineState)
drawCubes(encoder, scale: 1.0)

// 2. The outlines.
encoder.setDepthStencilState(outlineState)
encoder.setRenderPipelineState(solidColorPipelineState)
drawCubes(encoder, scale: 1.05)

// Floor and anything else that should not be outlined: the ordinary depth state.
encoder->setDepthStencilState(depthState);
drawFloor(encoder);

// 1. The cubes, marking the stencil buffer.
encoder->setDepthStencilState(writeState);
encoder->setStencilReferenceValue(1);
encoder->setRenderPipelineState(pipelineState);
drawCubes(encoder, 1.0f);

// 2. The outlines.
encoder->setDepthStencilState(outlineState);
encoder->setRenderPipelineState(solidColorPipelineState);
drawCubes(encoder, 1.05f);

Il solidColorPipelineState usa una fragment function che restituisce un colore unico.
Poiché lo state del contorno usa .always per la profondità, il bordo si vede attraverso gli altri oggetti, che è ciò che vuoi per evidenziare una selezione.

Contorni migliori

Scalare funziona per le forme convesse centrate sulla loro origine.
Per modelli qualsiasi sposta invece ogni vertice lungo la sua normale nella vertex function: position + normal * thickness.

Leggere il confronto nel verso giusto#

Il confronto si scrive riferimento op salvato.
Con .less e un riferimento pari a 1, un fragment passa dove 1 < salvato.
È facile leggerlo al contrario.

Altri usi#

  • Portali e specchi: disegna la forma del portale nello stencil buffer, poi disegna il mondo visto attraverso di esso solo dove lo stencil è impostato.
  • Maschere: ritaglia l'interfaccia o i contenuti 2D secondo forme qualsiasi.
  • Volumi di luce nel deferred: marca i pixel che una luce può raggiungere, così lo shader di illuminazione gira solo lì.

Esercizi#

  • Fai in modo che il contorno rispetti la profondità, così viene nascosto dagli oggetti più vicini.
    Mostra la soluzione

    Dai allo state del contorno un normale test di profondità: depthCompareFunction = .less al posto di .always.
    La copia ingrandita viene allora nascosta da tutto ciò che è più vicino alla camera.
    Nella demo interattiva togli la spunta a "ignore depth".

  • Metti il contorno a uno solo dei cubi.
    Mostra la soluzione

    Usa lo state che scrive nello stencil solo mentre disegni il cubo a cui vuoi dare il contorno, e disegna gli altri con il normale state di profondità.
    Poi disegna la copia ingrandita di quel solo cubo.
    Il valore di riferimento potrebbe anche distinguere gli oggetti: scrivi 1 per un cubo e 2 per un altro, e fai il test contro il valore che ti interessa.
