Cubemap#

Una cubemap è una texture fatta di sei immagini quadrate disposte come le facce di un cubo.
Si legge con una direzione 3D invece che con una coordinata 2D: immagina di stare al centro del cubo e di guardare lungo quella direzione, e ottieni il colore che vedi.
Le cubemap si usano per i cieli, per i riflessi e, più avanti, per le ombre omnidirezionali e per l'illuminazione basata su immagini.

Creare una cubemap#

Le sei facce sono salvate come sei slice di una sola texture di tipo .typeCube, nell'ordine +X, -X, +Y, -Y, +Z, -Z (destra, sinistra, alto, basso, davanti, dietro).

Da sei file immagine, la strada più breve passa per Model I/O:

let names = ["right.jpg", "left.jpg", "top.jpg", "bottom.jpg", "front.jpg", "back.jpg"]
let mdlTexture = MDLTexture(cubeWithImagesNamed: names)!
let skybox = try loader.newTexture(texture: mdlTexture, options: [.SRGB: false])

// Without MetalKit's loader: decode six files with stb_image and copy each into one slice.
const char* names[6] = {"right.jpg", "left.jpg", "top.jpg", "bottom.jpg", "front.jpg", "back.jpg"};
MTL::Texture* skybox = nullptr;
for (int face = 0; face < 6; face++) {
    int width, height, channels;
    unsigned char* pixels = stbi_load(names[face], &width, &height, &channels, 4);
    if (!skybox) {
        skybox = device->newTexture(MTL::TextureDescriptor::textureCubeDescriptor(
            MTL::PixelFormatRGBA8Unorm, width, false));
    }
    skybox->replaceRegion(MTL::Region::Make2D(0, 0, width, height), 0, face,
                          pixels, width * 4, width * height * 4);
    stbi_image_free(pixels);
}

Da una sola immagine che contiene le sei facce impilate dall'alto in basso, il texture loader la può dividere:

let skybox = try loader.newTexture(URL: url, options: [
    .cubeLayout: MTKTextureLoader.CubeLayout.vertical,
    .SRGB: false,
])

// One image with the six faces stacked top to bottom: each face is a block of rows.
int width, height, channels;
unsigned char* pixels = stbi_load("skybox_strip.png", &width, &height, &channels, 4);
int size = width;                                            // faces are square, height == 6 * width
MTL::Texture* skybox = device->newTexture(MTL::TextureDescriptor::textureCubeDescriptor(
    MTL::PixelFormatRGBA8Unorm, size, false));
for (int face = 0; face < 6; face++) {
    skybox->replaceRegion(MTL::Region::Make2D(0, 0, size, size), 0, face,
                          pixels + face * size * size * 4, size * 4, size * size * 4);
}
stbi_image_free(pixels);

A mano, quando le facce le generi o le decodifichi tu:

let descriptor = MTLTextureDescriptor.textureCubeDescriptor(pixelFormat: .rgba8Unorm,
                                                            size: 1024,
                                                            mipmapped: false)
let cube = device.makeTexture(descriptor: descriptor)!
for face in 0..<6 {
    cube.replace(region: MTLRegionMake2D(0, 0, 1024, 1024),
                 mipmapLevel: 0,
                 slice: face,
                 withBytes: facePixels[face],
                 bytesPerRow: 1024 * 4,
                 bytesPerImage: 1024 * 1024 * 4)
}

MTL::TextureDescriptor* descriptor = MTL::TextureDescriptor::textureCubeDescriptor(
    MTL::PixelFormatRGBA8Unorm, 1024, false);
MTL::Texture* cube = device->newTexture(descriptor);
for (int face = 0; face < 6; face++) {
    cube->replaceRegion(MTL::Region::Make2D(0, 0, 1024, 1024),
                        0,                       // mipmap level
                        face,                    // slice
                        facePixels[face],
                        1024 * 4,                // bytes per row
                        1024 * 1024 * 4);        // bytes per image
}

Uno skybox#

Uno skybox è un cubo disegnato intorno alla camera con una cubemap come texture, e dà l'illusione di un ambiente immenso.
La sua coordinata di texture è semplicemente la posizione locale del cubo, usata come direzione.

struct SkyOut {
    float4 position [[position]];
    float3 direction;
};

vertex SkyOut vertex_sky(VertexIn in [[stage_in]],
                         constant Uniforms &uniforms [[buffer(1)]]) {
    SkyOut out;
    float4 clip = uniforms.projection * uniforms.view * float4(in.position, 0.0);
    out.position = clip.xyww;
    out.direction = in.position;
    return out;
}

fragment float4 fragment_sky(SkyOut in [[stage_in]],
                             texturecube<float> sky [[texture(0)]],
                             sampler s [[sampler(0)]]) {
    return sky.sample(s, in.direction);
}

Nella vertex function ci sono due trucchi:

  • La posizione viene moltiplicata con w = 0, che elimina la traslazione della matrice view.
    Il cielo ruota con la camera ma non si avvicina mai.
  • L'uscita è clip.xyww.
    Dopo la divisione prospettica z diventa w / w = 1, il far plane.
    Il cielo finisce dietro a tutto.

Disegna il cielo per ultimo, dopo tutti gli oggetti opachi, con un depth state che usa .lessEqual e non scrive la profondità:

let skyDepth = MTLDepthStencilDescriptor()
skyDepth.depthCompareFunction = .lessEqual
skyDepth.isDepthWriteEnabled = false

MTL::DepthStencilDescriptor* skyDepth = MTL::DepthStencilDescriptor::alloc()->init();
skyDepth->setDepthCompareFunction(MTL::CompareFunctionLessEqual);
skyDepth->setDepthWriteEnabled(false);

Disegnato per ultimo, i fragment del cielo vengono scartati ovunque sia stato disegnato qualcos'altro, quindi il cielo costa solo i pixel in cui è visibile.
.lessEqual serve perché la profondità del cielo è uguale al valore di pulizia, 1.
La camera sta dentro il cubo, quindi disattiva il culling per questa draw call.

Sinistrorso o destrorso

Le cubemap usano una convenzione sinistrorsa, una stranezza storica comune a tutte le API grafiche.
Se nel tuo mondo destrorso uno skybox appare specchiato, cambia segno alla componente x o z della direzione nello shader.

Riflessione#

Con l'ambiente in una cubemap una superficie a specchio è facile: rifletti la direzione di vista intorno alla normale e usa il risultato per leggere il cielo.

fragment float4 fragment_reflect(VertexOut in [[stage_in]],
                                 constant FragmentUniforms &uniforms [[buffer(1)]],
                                 texturecube<float> sky [[texture(0)]],
                                 sampler s [[sampler(0)]]) {
    float3 incident = normalize(in.worldPosition - uniforms.viewPosition);
    float3 reflected = reflect(incident, normalize(in.normal));
    return sky.sample(s, reflected);
}

Combinala con una specular map per rendere riflettenti solo alcune parti di un modello.

Rifrazione#

La luce si piega quando passa da un mezzo a un altro.
refract calcola la direzione piegata dal rapporto tra i due indici di rifrazione:

Materiale Indice
Aria 1.00
Acqua 1.33
Vetro 1.52
Diamante 2.42 
float ratio = 1.00 / 1.52;   // from air into glass
float3 refracted = refract(incident, normalize(in.normal), ratio);
return sky.sample(s, refracted);

È una sola rifrazione alla superficie.
Fisicamente è incompleta, ma dà un aspetto di vetro convincente.

Disegnare dentro una cubemap#

Un cielo statico non può riflettere oggetti in movimento.
Per i riflessi dinamici disegna la scena sei volte dalla posizione dell'oggetto, una per faccia, con un campo visivo di 90 gradi e un rapporto d'aspetto di 1.
Scegli la faccia con lo slice dell'attachment:

pass.colorAttachments[0].texture = environmentCube
pass.colorAttachments[0].slice = face

pass->colorAttachments()->object(0)->setTexture(environmentCube);
pass->colorAttachments()->object(0)->setSlice(face);

Per via della convenzione delle cubemap queste sei viste vanno costruite con matrici view e projection sinistrorse, e i vettori up sono fissati:

Faccia Direzione di vista Up
+X ( 1, 0, 0) (0, 1, 0)
-X (-1, 0, 0) (0, 1, 0)
+Y ( 0, 1, 0) (0, 0, -1)
-Y ( 0, -1, 0) (0, 0, 1)
+Z ( 0, 0, 1) (0, 1, 0)
-Z ( 0, 0, -1) (0, 1, 0) 
extension float4x4 {
    init(lookAtLH eye: Float3, center: Float3, up: Float3) {
        let z = normalize(center - eye)
        let x = normalize(cross(up, z))
        let y = cross(z, x)
        self.init(columns: (
            SIMD4<Float>(x.x, y.x, z.x, 0),
            SIMD4<Float>(x.y, y.y, z.y, 0),
            SIMD4<Float>(x.z, y.z, z.z, 0),
            SIMD4<Float>(-dot(x, eye), -dot(y, eye), -dot(z, eye), 1)))
    }

    init(perspectiveLHFov fovY: Float, aspect: Float, near: Float, far: Float) {
        let y = 1 / tan(fovY * 0.5)
        let x = y / aspect
        let z = far / (far - near)
        self.init(columns: (
            SIMD4<Float>(x, 0, 0, 0),
            SIMD4<Float>(0, y, 0, 0),
            SIMD4<Float>(0, 0, z, 1),
            SIMD4<Float>(0, 0, -near * z, 0)))
    }
}

inline simd::float4x4 lookAtLH(simd::float3 eye, simd::float3 center, simd::float3 up) {
    simd::float3 z = simd::normalize(center - eye);
    simd::float3 x = simd::normalize(simd::cross(up, z));
    simd::float3 y = simd::cross(z, x);
    return simd_matrix(simd_make_float4(x.x, y.x, z.x, 0),
                       simd_make_float4(x.y, y.y, z.y, 0),
                       simd_make_float4(x.z, y.z, z.z, 0),
                       simd_make_float4(-simd::dot(x, eye), -simd::dot(y, eye), -simd::dot(z, eye), 1));
}

inline simd::float4x4 perspectiveLH(float fovY, float aspect, float near, float far) {
    float y = 1.0f / std::tan(fovY * 0.5f);
    float x = y / aspect;
    float z = far / (far - near);
    return simd_matrix(simd_make_float4(x, 0, 0, 0),
                       simd_make_float4(0, y, 0, 0),
                       simd_make_float4(0, 0, z, 1),
                       simd_make_float4(0, 0, -near * z, 0));
}

Una vista sinistrorsa specchia la scena, e questo inverte il winding dei triangoli, quindi usa setFrontFacing(.clockwise) mentre disegni le facce.
Riuseremo queste funzioni per le Ombre da luci puntiformi e per l'illuminazione basata su immagini.
Sei rendering della scena per frame costano molto; i motori aggiornano queste probe di rado, o una faccia per frame.

Esercizi#

  • Disegna lo skybox per primo invece che per ultimo, con la scrittura della profondità spenta, e misura la differenza nel GPU report di Xcode su una scena pesante.
    Mostra la soluzione

    Disegnato per primo, la fragment function del cielo gira per ogni pixel dello schermo, e la maggior parte di quei pixel viene poi ricoperta dalla scena.
    Disegnato per ultimo con .lessEqual, gira solo dove non è stato disegnato altro.
    Sulle GPU Apple la hidden surface removal riduce la differenza per i disegni opachi, ma disegnare il cielo per ultimo non è mai più lento.

  • Mescola riflessione e rifrazione con un fattore che dipende dall'angolo di vista.
    Mostra la soluzione

    Usa l'effetto Fresnel: più riflessione agli angoli radenti.

    float fresnel = pow(1.0 - max(dot(-incident, normal), 0.0), 5.0);
float3 color = mix(refracted, reflected, saturate(0.04 + 0.96 * fresnel));

    Nella demo interattiva sostituisci l'ultima riga dello shader con questa per avere una sfera di vetro dai bordi riflettenti.
