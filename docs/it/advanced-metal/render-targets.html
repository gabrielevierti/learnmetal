Metal avanzato

Render target#

Progetto di esempio examples/Sources/12-RenderTargets, si esegue con swift run RenderTargets. Scarica tutti gli esempi oppure guarda come eseguirli.

Finora ogni frame è stato disegnato direttamente nel drawable della vista.
Un render pass può invece disegnare in una texture qualsiasi, e quella texture può poi essere letta da un pass successivo.
Il rendering su texture è la base del post-processing, delle ombre, dei riflessi, del bloom e del deferred shading.
Quasi tutti i capitoli dopo questo lo usano.

Se vieni da OpenGL

Metal non ha framebuffer object.
Il loro ruolo lo svolge l'MTLRenderPassDescriptor: una descrizione leggera di quali texture sono gli attachment di colore, profondità e stencil di un pass.
Non c'è niente da collegare o scollegare, e non c'è alcun controllo di "completezza".

Creare le texture#

Una texture in cui disegni ha bisogno dell'uso .renderTarget.
Per leggerla in seguito le serve anche .shaderRead:

func makeOffscreenTextures(size: CGSize) {
    let width = max(Int(size.width), 1), height = max(Int(size.height), 1)

    let colorDescriptor = MTLTextureDescriptor.texture2DDescriptor(
        pixelFormat: .bgra8Unorm, width: width, height: height, mipmapped: false)
    colorDescriptor.usage = [.renderTarget, .shaderRead]
    colorDescriptor.storageMode = .private
    sceneColor = device.makeTexture(descriptor: colorDescriptor)!

    let depthDescriptor = MTLTextureDescriptor.texture2DDescriptor(
        pixelFormat: .depth32Float, width: width, height: height, mipmapped: false)
    depthDescriptor.usage = .renderTarget
    depthDescriptor.storageMode = .private
    sceneDepth = device.makeTexture(descriptor: depthDescriptor)!
}

void Renderer::makeOffscreenTextures(int width, int height) {
    width = std::max(width, 1);
    height = std::max(height, 1);

    MTL::TextureDescriptor* colorDescriptor = MTL::TextureDescriptor::texture2DDescriptor(
        MTL::PixelFormatBGRA8Unorm, width, height, false);
    colorDescriptor->setUsage(MTL::TextureUsageRenderTarget | MTL::TextureUsageShaderRead);
    colorDescriptor->setStorageMode(MTL::StorageModePrivate);
    if (sceneColor) sceneColor->release();
    sceneColor = device->newTexture(colorDescriptor);

    MTL::TextureDescriptor* depthDescriptor = MTL::TextureDescriptor::texture2DDescriptor(
        MTL::PixelFormatDepth32Float, width, height, false);
    depthDescriptor->setUsage(MTL::TextureUsageRenderTarget);
    depthDescriptor->setStorageMode(MTL::StorageModePrivate);
    if (sceneDepth) sceneDepth->release();
    sceneDepth = device->newTexture(depthDescriptor);
}

Lo storage .private significa che solo la GPU tocca la texture.
Chiama questa funzione da mtkView(_:drawableSizeWillChange:), così le texture seguono la dimensione della finestra.

Descrivere il pass#

let scenePass = MTLRenderPassDescriptor()
scenePass.colorAttachments[0].texture = sceneColor
scenePass.colorAttachments[0].loadAction = .clear
scenePass.colorAttachments[0].clearColor = MTLClearColor(red: 0.1, green: 0.1, blue: 0.1, alpha: 1)
scenePass.colorAttachments[0].storeAction = .store
scenePass.depthAttachment.texture = sceneDepth
scenePass.depthAttachment.loadAction = .clear
scenePass.depthAttachment.clearDepth = 1.0
scenePass.depthAttachment.storeAction = .dontCare

MTL::RenderPassDescriptor* scenePass = MTL::RenderPassDescriptor::alloc()->init();
scenePass->colorAttachments()->object(0)->setTexture(sceneColor);
scenePass->colorAttachments()->object(0)->setLoadAction(MTL::LoadActionClear);
scenePass->colorAttachments()->object(0)->setClearColor(MTL::ClearColor::Make(0.1, 0.1, 0.1, 1.0));
scenePass->colorAttachments()->object(0)->setStoreAction(MTL::StoreActionStore);
scenePass->depthAttachment()->setTexture(sceneDepth);
scenePass->depthAttachment()->setLoadAction(MTL::LoadActionClear);
scenePass->depthAttachment()->setClearDepth(1.0);
scenePass->depthAttachment()->setStoreAction(MTL::StoreActionDontCare);

Le load e store action meritano un momento di riflessione:

  • Il risultato di colore serve dopo, quindi viene salvato.
  • Il depth buffer serve solo durante il pass, quindi .dontCare permette alla GPU di buttarlo via.

Sulle GPU Apple una texture di profondità che non viene mai salvata si può perfino creare con storageMode = .memoryless.
Allora non occupa alcuna memoria, e vive soltanto nella memoria dei tile della GPU mentre il pass è in esecuzione.

Due pass in un frame#

func draw(in view: MTKView) {
    guard let commandBuffer = commandQueue.makeCommandBuffer() else { return }

    // Pass 1: the scene, into our texture.
    if let encoder = commandBuffer.makeRenderCommandEncoder(descriptor: scenePass) {
        drawScene(encoder)
        encoder.endEncoding()
    }

    // Pass 2: a full-screen triangle, into the drawable.
    guard let viewPass = view.currentRenderPassDescriptor,
          let drawable = view.currentDrawable,
          let encoder = commandBuffer.makeRenderCommandEncoder(descriptor: viewPass) else { return }
    encoder.setRenderPipelineState(postPipelineState)
    encoder.setFragmentTexture(sceneColor, index: 0)
    encoder.setFragmentSamplerState(samplerState, index: 0)
    encoder.drawPrimitives(type: .triangle, vertexStart: 0, vertexCount: 3)
    encoder.endEncoding()

    commandBuffer.present(drawable)
    commandBuffer.commit()
}

void Renderer::draw() {
    NS::AutoreleasePool* pool = NS::AutoreleasePool::alloc()->init();
    MTL::CommandBuffer* commandBuffer = commandQueue->commandBuffer();

    // Pass 1: the scene, into our texture.
    MTL::RenderCommandEncoder* sceneEncoder = commandBuffer->renderCommandEncoder(scenePass);
    drawScene(sceneEncoder);
    sceneEncoder->endEncoding();

    // Pass 2: a full-screen triangle, into the drawable.
    if (CA::MetalDrawable* drawable = layer->nextDrawable()) {
        MTL::RenderPassDescriptor* viewPass = MTL::RenderPassDescriptor::alloc()->init();
        viewPass->colorAttachments()->object(0)->setTexture(drawable->texture());
        viewPass->colorAttachments()->object(0)->setLoadAction(MTL::LoadActionDontCare);   // fully overwritten
        viewPass->colorAttachments()->object(0)->setStoreAction(MTL::StoreActionStore);

        MTL::RenderCommandEncoder* encoder = commandBuffer->renderCommandEncoder(viewPass);
        encoder->setRenderPipelineState(postPipelineState);
        encoder->setFragmentTexture(sceneColor, 0);
        encoder->setFragmentSamplerState(samplerState, 0);
        encoder->drawPrimitives(MTL::PrimitiveTypeTriangle, NS::UInteger(0), NS::UInteger(3));
        encoder->endEncoding();

        commandBuffer->presentDrawable(drawable);
        viewPass->release();
    }
    commandBuffer->commit();
    pool->release();
}

I pipeline state usati nel pass 1 devono dichiarare i formati degli attachment di quel pass.
Il pass di post-processing non ha bisogno di un attachment di profondità, quindi la sua pipeline lascia depthAttachmentPixelFormat non impostato; se la vista ha ancora un formato di profondità, impostalo perché coincida oppure metti view.depthStencilPixelFormat = .invalid.

Il triangolo a tutto schermo#

Per eseguire una fragment function su ogni pixel serve una geometria che copra lo schermo.
Basta un solo triangolo sovradimensionato, senza alcun vertex buffer.
La vertex function costruisce le posizioni dall'indice del vertice, che è un input predefinito:

struct ScreenOut {
    float4 position [[position]];
    float2 uv;
};

vertex ScreenOut vertex_fullscreen(uint vertexID [[vertex_id]]) {
    float2 uv = float2((vertexID << 1) & 2, vertexID & 2);   // (0,0) (2,0) (0,2)
    ScreenOut out;
    out.position = float4(uv * float2(2, -2) + float2(-1, 1), 0, 1);
    out.uv = uv;
    return out;
}

fragment float4 fragment_post(ScreenOut in [[stage_in]],
                              texture2d<float> scene [[texture(0)]],
                              sampler s [[sampler(0)]]) {
    return scene.sample(s, in.uv);
}

Il triangolo sporge oltre lo schermo e viene ritagliato su di esso.
Il ribaltamento di y fa cadere la uv (0, 0) sull'angolo in alto a sinistra, come l'origine delle texture di Metal, così una texture disegnata da un pass viene mostrata dritta dal successivo senza altre complicazioni.
La pipeline di post-processing non ha un vertex descriptor.

Eseguilo e la scena appare esattamente come prima.
Il punto è proprio questo: adesso passa attraverso una texture che possiamo manipolare.

Post-processing#

Inversione e scala di grigi cambiano un pixel alla volta:

float3 color = scene.sample(s, in.uv).rgb;
float3 inverted = 1.0 - color;
float gray = dot(color, float3(0.2126, 0.7152, 0.0722));

I pesi rispecchiano la sensibilità dell'occhio a ciascun canale.

Gli effetti a kernel combinano ogni pixel con i suoi vicini usando una piccola griglia di pesi, un kernel di convoluzione:

static float3 applyKernel(texture2d<float> tex, sampler s, float2 uv, const float kernel[9]) {
    float2 texel = 1.0 / float2(tex.get_width(), tex.get_height());
    float3 result = float3(0);
    for (int y = -1; y <= 1; y++) {
        for (int x = -1; x <= 1; x++) {
            float3 c = tex.sample(s, uv + float2(x, y) * texel).rgb;
            result += c * kernel[(y + 1) * 3 + (x + 1)];
        }
    }
    return result;
}

const float sharpen[9] = { -1, -1, -1,   -1,  9, -1,   -1, -1, -1 };
const float blur[9]    = { 1/16.0, 2/16.0, 1/16.0,   2/16.0, 4/16.0, 2/16.0,   1/16.0, 2/16.0, 1/16.0 };
const float edges[9]   = { 1, 1, 1,   1, -8, 1,   1, 1, 1 };

Usa un sampler con .clampToEdge, così ai bordi il kernel non rientra dal lato opposto.

Esercizi#

  • Disegna la scena a metà risoluzione e stirala sullo schermo.
    Confronta i filtri .nearest e .linear.
    Mostra la soluzione

    Crea le texture offscreen a metà della dimensione del drawable; il pass a tutto schermo le stira.
    Con .nearest vedi pixel raddoppiati e a blocchi, con .linear una sfocatura morbida.
    Disegnare a risoluzione ridotta e poi ingrandire è un modo consueto di risparmiare tempo di GPU, e MetalFX fa l'ingrandimento molto meglio di un filtro lineare.

  • Costruisci uno specchietto retrovisore: disegna la scena una seconda volta in una piccola texture, con la camera girata di 180 gradi, e mostrala su un rettangolo in alto sullo schermo.
    Mostra la soluzione

    Aggiungi una seconda piccola texture di colore e disegnaci la scena con una matrice view che guarda lungo -camera.front.
    Poi, nel pass principale, disegna vicino al bordo alto dello schermo un piccolo rettangolo che la legge.
    Specchia l'immagine in orizzontale ribaltando u, come fa uno specchio vero.
