How it works#

Each chapter introduces one idea, explains why it works, and shows the code that implements it.
Chapters build on each other, so by the end you have a small renderer you understand line by line.

  • Swift or C++.
    Pick your language with the switch in the top bar.
    Swift uses MetalKit; C++ uses Apple's metal-cpp with GLFW.
    Every chapter is available in both.
  • Live demos.
    The demos run in your browser.
    The shader you edit is real Metal Shading Language, translated on the fly so it can run on any platform.
  • Example projects.
    Runnable projects for the main chapters are in the repository and can be downloaded.
  • A game engine at the end.
    The last chapters of In Practice put every technique together in a small engine with a playable game, in Swift and in C++.

You need a Mac with Xcode to run Metal itself.
