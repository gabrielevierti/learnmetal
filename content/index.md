## What is this?

learnmetal is a free tutorial series that teaches real-time 3D graphics from the ground up using **Metal**, the graphics API on every Mac, iPhone, iPad, Apple TV and Vision Pro. You start with an empty window and finish with shadows, HDR, deferred shading and physically based rendering.

Every chapter introduces one idea, explains why it works, and shows the Swift and Metal Shading Language code that implements it. Each chapter builds on the code from the one before, so by the end you have a small renderer you understand line by line.

## Code and figures

Runnable Swift examples for the main chapters are in the repository's `examples/` folder and can be [downloaded as a zip](downloads/learnmetal-examples.zip). See [Example Code](resources/examples.html) for how to run them.

The figures are illustrations drawn by a small software renderer that implements each chapter's shading math. They are not screenshots of the Metal examples.

## Who is it for?

- Programmers who know some Swift and want to learn graphics programming.
- People coming from OpenGL, Vulkan or Direct3D who want to see how the same ideas look in Metal. Look for the **Coming from OpenGL** boxes.

You need a Mac with Xcode. High school level vectors and matrices help, but the math is explained as it comes up.
